# 플랫폼 계약

| 책임 | 공통 | macOS 브라우저 예제 | Windows 브라우저 예제 |
| --- | --- | --- | --- |
| 제품 화면 | 회의, 참석자/그룹, 자료, 전사, 질문, 회의록 | `prototype/` 재사용 | 동일 `prototype/` iframe 재사용 |
| 색상 | 무채색 light/dark, 녹음/오류/경고의 의미색 | 공유 CSS | 공유 CSS |
| 글꼴 | system/Korean fallback | 공유 `--font-ui/--font-code` | 외곽/iframe 모두 같은 공통 글꼴 계약 |
| 녹음 상태 | 준비/녹음/일시정지/종료/오류 의미 | 메뉴 막대, 노치/부유 제어기 | 트레이, 부유 제어기 |
| 알림 | 제목, 남은 시간, 열기/미루기/닫기 | 한 줄 compact 알림 | Windows 형식의 브라우저 알림 |
| 창 | 제품 정보 계층 | 앱 호스트/데스크톱 예시 | 제목 표시줄, 최소화/최대화/닫기, 복귀 |
| 저장 | 시안 전용 namespace | 독립된 예제 상태 | iframe 전용 세션 |

공통 콘텐츠와 상태를 플랫폼 표면이 복제해서 소유하지 않는다. Windows 부모는 창/알림/트레이 표시를 소유하고 녹음 상태는 같은 출처의 iframe 메시지로 받는다. 메시지 수신은 source와 origin을 확인하며 종료 명령은 녹음 소유 ID를 대조한다.

노치와 메뉴 막대를 Windows 규칙으로 확대하지 않는다. Windows caption/트레이/알림 치수는 브라우저 참고값이며 OS의 검증된 치수나 네이티브 동작 계약이 아니다. 양쪽 배경은 앱 테마와 별도의 중립색을 사용한다.

## 아직 검증하지 않은 것

- 실제 macOS/Windows 마이크 권한, 녹음과 중단/복구
- OS 창 레벨, 전체 화면/다중 모니터, 디스플레이 배율, 트레이 등록
- 네이티브 알림 전달, 집중 모드, 바로가기 등록과 다른 앱에서의 포커스 이동
- 실제 Windows 글꼴 선택과 125/150/200% 디스플레이 배율
- VoiceOver/Narrator, 시스템 고대비, 키보드 배치와 IME의 네이티브 통합

브라우저의 클릭/키보드/상태 전환 검사는 위 네이티브 검증과 구분한다. 구현 시에도 상태 소유권은 공통 로직에 두고 각 플랫폼 창/알림 어댑터가 표시를 맡는다.

## 네이티브 구현

새 앱은 `apps/desktop/`의 Tauri와 `crates/nero-core/`의 공통 Rust 코어를 사용한다.
위 플랫폼 표는 브라우저 예제의 계약이다. 첫 네이티브 구현에는 마이크 입력,
원음 보존, 재생과 compact 제어 창이 있으며 실제 OS 수용 검증은 별도로 남아 있다.

현재 네이티브 제품은 별도 메뉴바/트레이 상주 아이콘을 등록하지 않는다. macOS는 Dock에서 숨긴 본창을 다시 열고, Windows의 본창 닫기는 미저장 편집과 녹음 확인을 거치는 정상 종료를 요청한다. 녹음용 노치/상단 패널과 부유 제어기는 유지한다. 위 브라우저의 메뉴바/트레이 시연은 과거 플랫폼 비교 예제이며 현재 제품의 상주 아이콘 계약이 아니다.
