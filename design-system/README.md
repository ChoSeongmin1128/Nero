# Nero 디자인 시스템

재작성 UI의 공통 글자 규칙, 컨트롤, 반복 뷰와 브라우저 예제를 관리한다. 이 디렉터리가 정본이며 legacy Swift 앱과 사용자 라이브러리는 사용하지 않는다. Tauri 앱은 `apps/desktop/scripts/prepare-shared.mjs`로 공통 소스를 `.generated/shared`에 복사해 빌드한다. 생성본은 수정하지 않는다. 브라우저 예제는 네이티브 기능 검증을 대신하지 않는다.

배경, 본문, 보조 글자, 테두리, 선택, 링크와 주요 동작은 무채색을 사용한다. light에서는 어두운 주요 버튼, dark에서는 밝은 주요 버튼을 사용한다. 선택은 배경 명도, 테두리와 글자 굵기로 구분하고 색상만으로 상태를 전달하지 않는다. 오류/경고/녹음의 의미색은 유지한다.

## 책임

| 파일/경로 | 소유하는 것 |
| --- | --- |
| `appearance.css`, `appearance.js` | 흑백 색상과 의미별 상태색, light/dark 선택 |
| `fonts.css`, `typography.css` | 동봉 UI 글꼴 로딩, UI/코드 글꼴과 크기/굵기/줄간격/자간 역할 |
| `components.css` | 버튼, 입력, 필드, 배지, 선택, 내용 탭, 오류, 모달, 설정 선택의 기본 스타일 |
| `navigation.mjs`, `navigation-width.mjs`, `navigation.css`, `action-menu.mjs` | 최근 회의 행/회의 작업 메뉴, hover 탐색, 너비 조절과 메뉴 위치/키보드/닫기 동작. 제품과 탐색 시안이 같은 구현 사용 |
| `components.js` | 버튼/상태/회의 행/사람 행/참석자 항목/전사 발언/회의록 읽기/모달 내용 생성 |
| `controls.css`, `controls.js`, `react-controls.jsx`, `components/ui/` | shadcn/ui Base 레지스트리에서 조정한 React/Base UI 선택/Popover/Dialog와 한국어 React DayPicker. 원래 native 입력의 값/이벤트 어댑터와 DOM 수명 관리 |
| `style.css`, `prototype/` | 브라우저 제품 예제의 배치와 기능 상태 |
| `../apps/desktop/src/style.css` | 네이티브 앱 배치와 기능별 크기. 입력 테두리/배경/안쪽 여백은 공통 스타일 사용 |
| `desktop-preview-*`, `windows-preview/` | 각 플랫폼의 창/알림/녹음 표시와 공통 상태 연결 |
| `catalog/` | 같은 공통 컴포넌트의 역할/상태/상호작용 예제와 생성 토큰 |
| `checks/` | 공통 뷰와 소비처, 토큰, Windows 연결의 회귀 검사 |
| `vendor/` | Lucide와 Pretendard 원본, 출처와 라이선스 |

그룹 편집, 화자 지정과 자료 연결 같은 기능별 구성은 해당 화면이 소유한다. 모든 화면을 하나의 범용 컴포넌트로 바꾸지 않는다. 공통 뷰가 회의 상태, 참석자 선택, 저장, 스크롤 복원이나 외부 호출을 소유하지 않는다.

## 화면과 상태 계약

- 접힘 탐색은52px이며 전체 목록/폴더/휴지통/최근 회의 아이콘을 유지한다. 펼치면 별도 아이콘 열 없이 저장된 너비를 사용한다. 이전/다음, 사이드바 토글과 새 회의는 항상 보이는 앱 상단 도구 행에 한 번만 둔다. 알림은 사이드바 내부 상단 우측에 둔다. 축소된 아이콘에는 접근 가능한 이름과 도구 설명을 제공한다.
- 본문 요약과 음성 기록은 같은 문서 흐름, 메모는 독립 보조영역이다. 창이 좁아져도 본문을 숨기지 않는다. 읽기 영역은 한 스크롤, 검색 도구는 고정한다.
- 기본 컨트롤32px/작은 동작28px, 관리행40px이상, 아이콘16px, 그룹간격16px, 구역간격24px을 공통 토큰으로 사용한다. 글자가 길면 높이가 늘어난다.
- 설정의 이진 값은 중앙 정렬된 switch, 배타적 선택은 radio, 여러 항목 선택은 checkbox를 사용한다. 상태/설명/오류를 중복 표시하지 않는다.
- 테마/탐색/목록 재배치는180ms, reduced-motion에서는 즉시. 최초 표시에는 모션이 없다. 목록 조작 중 정렬 순서를 고정하고 포커스/스크롤/입력값을 유지한다.
- 준비된 앱 업데이트는 하단 단일 동작, 진행은 작은 진행률, 오류/대기는 이유를 표시한다. 재시작은 사용자 동작과 저장/녹음 안전 게이트를 거친다.

## 글자

| 역할 | 크기 | 줄간격 | 용도 |
| --- | ---: | ---: | --- |
| body | 14px | 1.5 | 기본 UI와 입력 |
| label | 13px | 1.5 | 조작 이름과 짧은 이름 |
| caption | 12px | 1.5 | 날짜/시각/상태/보조 정보 |
| aux | 11px | 1.5 | 제품 밖의 검토 도구 메타 정보 |
| subtitle | 15px | 1.5 | 소제목 |
| reading | 16px | 1.75 | 별도의 읽기 강조 역할 |
| heading | 18px | 1.35 | 구역 제목 |
| title | 24px | 1.35 | 회의 제목 |
| display | 26px | 1.35 | 페이지 제목 |
| timer | 13px | 1.5 | UI 글꼴과 `tabular-nums` |
| code | 12px | 1.5 | 코드 글꼴 |

Mac과 Windows의 웹 UI는 동봉한 Pretendard Variable 1.3.9를 같은 계약으로 사용한다. `fonts.css`는 수정하지 않은 WOFF2 원본을 로컬 상대 경로로 로딩하며 CDN이나 OS 글꼴 설치가 필요 없다. 전체 글꼴과 OFL 1.1 고지·출처·해시는 `vendor/pretendard/`에서 관리하고 앱과 시안에 함께 포함한다. 글꼴 로딩 전이나 미지원 문자는 기존 OS 글꼴로 대체한다. 독립적인 OAuth 콜백 페이지와 OS 네이티브 창 장식은 시스템 글꼴을 유지한다. 코드 이외의 본문과 타이머에 고정폭 글꼴을 쓰지 않는다. 기존 `--body/--display/--mono`는 호환 alias다. 전사/회의록은 기존 읽기 밀도를 유지해 body 크기와 reading 줄간격을 조합한다. 역할의 실제 계산값은 카탈로그에서 확인한다.

일반 컨트롤 높이는 `--control-height` 32px, 작은 동작은 `--control-height-small` 28px를 사용한다. 공통 컨트롤 반경은 6px, 묶음/대화창 반경은 8px다. 긴 문구가 줄바꿈되면 최소 높이보다 늘어날 수 있으며 글자를 잘라 높이를 강제하지 않는다. 편집하지 않는 회의 제목은 입력 테두리를 숨기고 hover/focus에서 편집 경계를 드러낸다.

## 공통 뷰

`NeroUI`는 HTML을 반환하고 이벤트는 소비 화면에 남긴다. 일반 사용자 문자열은 `text`나 지정된 데이터 속성으로 전달한다. `html/contentHTML/bodyHTML/actionsHTML`은 앱이 만든 신뢰 가능한 조합에만 사용하고, 그 안의 사용자 문자열은 `NeroUI.escape()`로 처리한다. 속성 이름은 허용된 HTML/ARIA/data 목록만 받는다.

카탈로그와 제품은 `meetingRow/personRow/personOption/utterance/minutes/dialogContent`를 함께 사용한다. 기능별 시간/수정/참석자 선택의 기존 `data-action/data-field/id`를 유지한다. 선택 메뉴와 달력도 같은 `NeroControls`를 사용한다.

선택/날짜는 같은 canonical React 소스를 사용한다. 앱은 Vite import로 기능 모달과 React 런타임을 공유하고, 정적 카탈로그/시안은 `build-controls.mjs`로 같은 엔트리를 standalone `controls.js`로 묶는다. 원본 `controls.js`는 빌드 입력이므로 소스 폴더를 그대로 HTTP에 올리지 말고 `build-preview.cjs`의 결과를 사용한다. React는 전용 host만 소유하며 소비 화면의 원래 native 입력, 저장, 녹음 상태를 소유하지 않는다. 출처/고정 커밋/원본 해시/MIT 고지는 `components/ui/`에 있고 앱에도 라이선스를 포함한다.

휴지통 이동과 삭제는 `.danger-text` 또는 `button.danger`를 사용한다. `--danger-text`와
`--danger-surface`가 테마와 밝기에 맞는 위험 동작 색상을 소유하며, 일반 버튼/헤더 색상이
덮어쓰지 않는다. 휴지통 보기로 이동하는 탐색 메뉴와 복원 동작에는 위험 색상을 적용하지 않는다.

설정은 `.settings-group`으로 구획을 나누고 `.settings-row`로 이름과 현재 값/조작을 좌우에 배치한다. 공통 행은 최소 48px이며 테마의 테두리와 반경을 사용한다. 연결처럼 오류가 별도 줄을 사용하는 구성과 창/탭의 배치는 앱이 소유한다. 연결 완료 상태에는 중복 연결 버튼을 두지 않고, 재연결이 필요한 상태에서만 버튼을 다시 표시한다.

앱 설정은 일반/녹음/연동/참석자/요약 템플릿으로 탐색한다. 선택 회의 요약의 추가/진행/취소는 일반 안의 같은 행에 두며 별도 모델 페이지로 이동하지 않는다. 연동의 AI 에이전트와 Google Calendar는 제목과 간격으로 구분한다. 설치 여부와 실제 세션 상태는 구분하며 확인되지 않은 설치를 업데이트 필요로 단정하지 않는다.

문서의 복사/내보내기는 같은 Popover 구성과 텍스트/마크다운 형식 선택을 공유한다. 요약 인용 포함은 기본 해제이며 앱 저장 원본에는 영향을 주지 않는다. 실패는 해당 메뉴에 표시하고 닫은 뒤 원래 버튼으로 초점을 돌린다.

일반 입력은 `.text-input`, 검색은 `.text-input--compact`, 제목은 `.text-input--title`을 사용한다. 기본/호버/포커스/읽기 전용/비활성 경계와 안쪽 여백은 `components.css`가 소유한다. `.editor`처럼 외부 프레임이 입력 영역을 소유하는 문서 편집 변형에는 중복 적용하지 않는다.

내용 탐색은 `.content-tabs`와 `tablist/tab/tabpanel`을 사용한다. 선택은 `aria-selected`,
초점 순서는 roving `tabindex`로 표현한다. 좌우 방향키와 Home/End는 해당 탭을 선택하며,
공통 오디오와 편집 DOM을 다시 만들지 않는다. 저장/읽기/스크롤 복원은 기능 화면이
소유하고, 로딩과 빈 상태를 구분한다. 카탈로그의 같은 구성으로 선택/초점/긴 내용 스크롤을 확인한다.

회의 분류의 기본 항목과 사용자 폴더는 같은 이름/개수/메뉴 열을 사용한다. 개수는
오른쪽 정렬과 `tabular-nums`를 적용하고, 메뉴가 없는 항목도 같은 열 폭을 유지한다.
선택 상태는 현재 목록 필터를 나타내며 열린 회의의 실제 폴더는 상세 상단에 별도로 표시한다.
음성 기록은 창 전체가 아닌 기록 영역의 폭에 맞춰 배치한다. 좁은 영역에서는 시간/화자를
본문 위로 옮기고 편집 본문과 동작도 본문 폭을 사용한다.

설정 탐색의 선택 표시는 `settings-navigation`과 `aria-selected`가 소유한다. 선택한 탭만 강조색 면/테두리를 가지며, 비선택 hover는 중립색 면만 사용한다. 키보드 초점은 별도 외곽선으로 유지한다.

스타일을 바꿀 때는 소유 파일을 수정한다. 카탈로그에만 별도 제품 스타일을 덧붙이지 않는다. 간격/반경/높이의 모든 숫자를 하나의 scale로 만들지 않으며, 공통 컴포넌트의 반복 기준과 각 플랫폼 구조의 차이를 구분한다.

## 사용과 검사

Nero 저장소 루트에서 실행한다.

```sh
node design-system/checks/check-design-contracts.cjs
node --test design-system/checks/check-components.cjs
node design-system/checks/check-windows-bridge.cjs
node design-system/catalog/build-tokens.cjs
node design-system/catalog/check-tokens.cjs
node design-system/build-preview.cjs --output .work/design-system-preview
python3 -m http.server 8792 --bind 127.0.0.1 --directory .work/design-system-preview
```

`/catalog/`, `/prototype/`, `/windows-preview/`에서 검토한다. 소스 변경 후 생성 토큰을 검토하고 다시 만든다. `tokens.json`을 직접 편집하지 않는다. 생성기는 원본 아래 출력, 심볼릭 링크, 소유 표식 없는 기존 출력과 무관한 파일이 있는 출력을 거부한다.

브라우저 예제 저장은 `nero-design-system-v1-*` 전용 namespace다. 실제 앱은 `nero.appearance.v1`의 밝기 설정을 같은 `appearance.js`로 초기 적용하며 메인/작은 창이 공유한다. 원래 v3 시안의 데이터를 자동으로 가져오지 않는다. 카탈로그는 페이지 메모리, Windows는 분리된 시연 세션을 사용한다. 실제 마이크/외부 계정/OS 알림은 사용하지 않는다.

## 목록 선택과 삭제 동작

회의 목록은 별도 선택 모드 없이 체크박스/Space로 선택한다. 체크박스 자리는 항상 유지하며 hover/focus 또는 하나 이상 선택된 상태에서 표시한다. 터치/고대비 환경에서는 항상 표시한다. 일반 클릭은 열기, Cmd(macOS)/Ctrl(Windows)+클릭은 추가 선택, Shift는 현재 표시 순서의 범위 선택이다. 목록 안의 Cmd/Ctrl+A는 현재 결과만 선택한다. Esc는 열린 메뉴/대화창을 먼저 닫고 그 뒤 선택을 해제한다. 검색/폴더 이동 후 보이지 않는 선택은 남기지 않는다.

선택이 있을 때만 제목 옆에 개수/일괄 작업을 표시한다. 이동, 복원, 휴지통/영구 삭제, 선택 해제는 같은 작은 아이콘 버튼과 접근성 이름/도움말을 쓴다. 메뉴와 확인창은 동작 이름을 표시한다. 삭제 계열은 공통 danger 색상을 사용한다. 본문의 휴지통 비우기는 아이콘+텍스트, 사이드바 휴지통 미리보기는 같은 이름의 아이콘 버튼을 쓴다. 두 진입점은 같은 비활성 상태와 삭제 확인 흐름을 공유하며 검색/선택에 관계없이 확인한 휴지통 전체를 대상으로 한다. 영구 삭제 확인창은 대상 개수를 표시하고 취소에 먼저 초점을 둔다. 개별 기능의 삭제 검증/저장은 소비 화면의 책임이다.

## 제품 범위

현재 MVP 우선순위는 녹음과 음성 보존, 한국어 전사, 회의 안의 기본 화자 구분, 전사에 근거한 요약이다. 자료 질문/연결 자료 검색/지식 보강 예제는 후속 범위이며 취소한 기능은 아니다. 실시간 전사의 MVP 필수 여부는 미결이다. 등록 화자 자동 이름 연결은 기본 화자 구분과 별도다.

## 검증 경계

코드 검사는 네이티브 앱의 공유 CSS 패키징/로딩과 제목/메모 입력의 외형 덮어쓰기 방지, 공통 소유권, 이벤트 속성/문자열 처리, 토큰 참조/변경 일치, 테마와 Windows 명령의 출처/녹음 소유 ID를 확인한다. 브라우저의 입력/포커스/선택/읽기 밀도와 열린 메뉴/달력 검사는 별도다.

실제 Windows 글꼴 선택, 125/150/200% 디스플레이 배율, 고대비/Narrator와 macOS VoiceOver/OS 권한/패널/다중 모니터는 아직 네이티브 검증되지 않았다. 웹의 계산된 `font-family` 문자열은 각 글자에 실제 선택된 폰트의 증거가 아니다. Nero 로고와 초기 설정은 앱에 반영되어 있다. 브라우저 시안에는 후속 기능 예제가 포함되어 있으므로 현재 앱의 기능 범위는 `../apps/desktop/README.md`를 따른다.

## 탐색 공통 계약

`navigation.mjs`와 `navigation.css`가 실제 앱과 탐색 시안의 단일 사이드바 제어를 소유한다. 제품의 접힌 탐색에는 전체 목록/폴더/휴지통/최근 회의 아이콘이 남는다. 마우스 hover 또는 키보드 초점으로 해당 목록을 오른쪽에 겹쳐 표시하며, 이 동작은 본문과 방문 이력을 변경하지 않는다. Enter/오른쪽 방향키로 표시된 목록에 진입하고, 첫 항목에서 Shift+Tab 또는 목록 버튼에서 왼쪽 방향키로 원래 아이콘에 복귀한다. 입력과 열린 메뉴의 키 동작은 유지한다. 목록과 아이콘 사이 포인터 이동, 검색 입력, 열린 메뉴가 임시 패널을 유지한다. Escape는 열린 메뉴를 먼저 닫는다.

펼친 제품 사이드바에는 별도 아이콘 열이 없으며 알림은 내부 상단 우측에 배치한다. 이전/다음, 단일 사이드바 토글과 새 회의 아이콘은 사이드바 밖의 고정 상단 도구 행에 둔다. 설정/업데이트 버튼만 상태에 맞는 슬롯으로 이동해 중복하지 않는다. 최근 회의, 전체 목록과 휴지통 미리보기는 같은 2행 회의 컴포넌트와 작업 메뉴를 사용한다. 제목/폴더와 시각/녹음 길이는 각기 구별한다. 최근 접기와 폴더별/전체 보기는 각각 유지한다. 목록/폴더/회의 경로는 클릭할 수 있고 좁은 창에서도 제목/재생기를 유지한다. 제품의 새 회의는 상단의 단일 아이콘 동작이며 빈 회의 안에서 녹음/음성 가져오기와 일정 연결을 선택한다. Calendar 일정 선택은 공통 dialog/calendar/popover/radio/button/focus 반환을 사용하며 준비 버튼 전에는 회의를 생성하지 않는다. 모달 위의 선택창/달력은 공통 layer 토큰을 사용하고 포인터 선택과 Escape 복귀까지 확인한다.

접힌 카테고리 미리보기가 없는 과거 브라우저 예제는 단일 열기 버튼/가장자리 hover를 유지한다. 해당 예제의 레일이나 생성 동작을 현재 제품 구현으로 간주하지 않는다.

탐색의 기본 보기(회의 목록/미분류), 사용자 폴더, 휴지통은 별도 그룹이다. 폴더 추가는 폴더 제목 옆에 두며 폴더가 없을 때도 추가 경로를 유지한다. 같은 행 컴포넌트의 선택/초점/드롭 규칙을 공유한다.

접힘, 임시 펼침, 펼침 유지 상태를 구분한다. 헤더의 고정 슬롯과 사이드바 사이에서 단일 버튼만 이동하며 별도 pin 아이콘이나 중복 생성/탐색 도구를 노출하지 않는다. 임시 펼침은 본문을 어둡게 하지 않고 위에 놓이며, 펼침 유지는 본문 폭을 조정한다. 패널 위치와 본문 그리드는 공유 motion 토큰으로 전환하고 reduced-motion에서는 즉시 바꾼다. fixed 메뉴의 viewport 좌표 계약을 유지하도록 사이드바에 transform을 적용하지 않는다.


### 새 회의와 알림의 제품 경계

사이드바의 새 회의는 하나의 전체 폭 동작이다. 일정 연결과 음성 가져오기는 선택한 빈 회의 안에 배치한다. 같은 초안의 제목, 메모, 폴더를 유지하며, 녹음/음성이 있으면 연결 동작을 노출하지 않는다. 편집 중 비동기 결과가 도착해도 포커스된 메모 편집기를 재생성하거나 다른 패널로 이동하지 않는다.

별도 알림 화면은 실제 작업 ID/상태/시도를 사용한다. 본문에는 현재 회의에 필요한 상태만 표시한다. 다른 회의의 과거 실패/취소를 상단 배너로 쌓지 않는다. 재시도는 해당 작업의 최신 시도에만 적용하며, 확인은 알림 표시만 종료하고 작업 영수증을 보존한다. 초기 진입에서 과거 완료 작업을 새 알림으로 복원하지 않는다. 측정된 다운로드만 백분율을 표시하고 모델 추론은 진행 표시를 사용한다.

## 사이드바 너비

공통 navigation controller가 하나의 separator를 생성하고 고정 또는 hover로 열린 상태에서만 표시한다. 기본 224px, 최소 200px, 최대 400px이며 펼침 유지에서는 본문에 400px을 남긴다. 600px 미만에서 펼침 유지를 overlay로 바꾸며 바깥 영역을 최소 48px 남긴다. 임시 펼침은52px 축소 탐색 오른쪽에 놓고 해당 너비와 바깥48px을 제외한 범위로 제한한다. 너비 조절선은 각 모드의 실제 패널 오른쪽 경계에 놓는다. 저장한 선호 너비와 화면에 맞춘 실제 너비를 구분하므로 작은 창에서 다시 넓혀도 선호가 복원된다.

드래그는 frame마다 미리 보기만 갱신하고 정상 종료 때 저장한다. Escape, pointer cancel, capture loss, 창 blur, 숨김과 크기 변경은 미리 보기를 취소한다. separator는 방향키로 8px씩, Home/End로 현재 범위의 양 끝으로 조절하고 더블클릭으로 기본값을 복원한다. 접기 버튼과 hover 상태는 navigation controller가 계속 소유한다.
