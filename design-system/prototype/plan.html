Nero 시안 열기 다양한 사례

회의의 준비부터 보관까지

MVP는 녹음과 음성 보존, 한국어 전사, 기본 화자 구분, 전사에 근거한 요약을 우선합니다. 실시간 전사의 필수 여부는 미결입니다. 아래 자료 질문과 지식 관리 동선은 후속 검토 예제를 포함합니다.

회의 하나를 준비하고 녹음하며, 대화와 자료를 참고해 회의록을 완성하는 작업 공간입니다. 가상 데이터로 동선을 검토하는 시안이며 실제 녹음, AI 호출, 계정 인증, Notion 저장은 하지 않습니다.

데스크톱에서 회의하기

상단 데스크톱 시안을 열어 조작합니다.

  1. 한 줄에 제목, 남은 시간, 미루기/닫기를 표시합니다. 제목을 누르면 회의 준비로 이동하며 녹음을 바로 시작하지 않습니다. 일반 알림에는 별도 열기 버튼을 중복 표시하지 않습니다.
  2. 본창에서 녹음을 시작한 뒤 데스크톱/화상회의 배경으로 전환합니다. 상단 노치는 176x33px(32px 행+1px 경계)이며, 마우스를 올리거나 클릭하면 236px 한 줄로 펼쳐집니다.
  3. 노치를 아래로 끌어 부유창으로 분리합니다. 부유창은 축소 시176x44px, 펼침 시236x44px이며, 상단 드롭 영역에 놓아 다시 붙입니다. 일시정지하거나 제어기를 숨긴 뒤 Nero 메뉴에서 복원해도 시간과 부유창 위치를 유지합니다.
  4. 종료 확인에서 녹음을 끝내고 해당 회의록으로 돌아갑니다.

상황 버튼으로 마이크 권한/연결 끊김/다른 회의 녹음을 확인합니다. 5분 경과로 시연 시간을 앞당길 수 있습니다.

제목 예시에서 긴 제목/공백 없는 제목을 선택합니다. 말줄임된 제목에 마우스를 올리거나 Tab으로 포커스를 두면 전체 제목을 표시합니다. 제목과 tooltip을 벗어나거나 Escape를 누르면 닫습니다. 별도 전체/접기 버튼은 없고 짧은 제목도 클릭해 회의를 열 수 있습니다. 준비 → 녹음 → 종료에서도 같은 제목을 확인할 수 있습니다.

크기는 브라우저 CSS 시안값이며 Meetings 실측값이나 Nero 네이티브 적용값이 아닙니다. 실제 OS 창/알림/메뉴바/마이크는 사용하지 않습니다. 시연을 닫으면 원래 회의와 읽던 위치로 돌아갑니다.

외관

사이드바 하단 설정에서 색상과 밝기를 각각 고릅니다. Nero(녹색), Slate(파랑), Iris(보라), Mono(흑백), Ochre(황토), Rose(장미)에 밝게/어둡게/시스템을 적용할 수 있습니다. 시스템은 선택한 색상을 유지하며 밝기만 따라갑니다. 카드도 선택한 밝기의 미리보기를 표시합니다.

본문의 글꼴과 밀도는 유지하고, 사이드바와 주변 면에는 선택한 색상 기운을 남깁니다. 중앙 읽기 면은 선명한 중립색과 작은 바깥 여백으로 구별합니다. 주요 행동은 테마 강조색, 선택은 약한 채움과 경계, 근거와 링크는 별도 보조색으로 구별합니다. 화자 표식은 테마와 독립된 보조색을 사용하며, 녹음과 주의 상태는 별도 색과 글자로 표시합니다. 흑백 테마는 강조와 선택, 준비 상태, 아바타까지 무채색으로 맞추고 녹음/경고의 의미색만 유지합니다. 설정의 선택은 카드 내부 체크와 얇은 경계, 키보드 포커스는 별도 링으로 표시합니다. 메모, 생성 초안, 전사 원문은 계속 구분합니다.

목록과 참석자

최근 회의는 실제 열람 이력이며, 설정에서 회의 날짜순과 표시 개수를 바꿉니다. 날짜 미정은 날짜순 정렬의 마지막에 둡니다. 날짜/정렬 메뉴는 선택 표시, 방향키 이동과 Escape 복귀를 지원합니다.

참석자 검색은 전체 명단에서 찾고 검색어가 없을 때 그룹/선택 범위를 표시합니다. 새 사람은 이름/역할을 확인해 등록하고, 적용 전에 선택 해제한 임시 사람은 등록하지 않습니다. 같은 이름은 역할로 구별합니다. 한글 조합 중 입력창을 바꾸지 않으며 실제 OS 입력 재현은 별도 확인 대상입니다.

Notion에서 참고할 원칙

원칙 Nero에 적용
회의 정보와 시작을 한곳에 준비 화면에 이미 모여 있습니다. 이번 외관 비교에서 동선은 바꾸지 않습니다.
메모를 회의록의 재료로 현재 메모가 초안 입력에 포함됩니다. 시안에서는 내용을 이어 붙이며 AI 요약은 아닙니다. 메모의 용도와 기본 행동의 위계는 보완 대상입니다.
끝나면 초안을 준비 종료 후 자동 생성은 미결입니다. 실패, 재시도, 기존 편집 보존 기준을 정한 뒤 검토합니다.
참석자와 발언자를 구분 명단과 전사의 발언자는 별도로 유지합니다. 공유 권한과 녹음 동의는 아직 구현하지 않았습니다. 외부 AI 자료 전달 동의를 대신 쓰지 않습니다.
작업 중 필요한 행동을 가까이 실시간 질문 접근을 유지합니다. 큰 여백, 반복 제목, 긴 회색 사용법은 가져오지 않습니다.

회의 찾기

사이드바에는 실제 최근 열람 이력을 보여주며, 설정에서 날짜순과 표시 개수를 바꿉니다. 모든 회의에서 이름, 참석자, 메모와 회의록을 검색하고 날짜와 상태를 좁힙니다. 결과는 16개씩 표시하며 이전/다음 또는 페이지 선택으로 이동합니다. 검색 중에도 녹음은 해당 회의에서 계속됩니다.

다양한 사례

16개 회의 살펴보기: 36명 참석, 긴 제목과 이름, 동명이인, 참석자와 날짜 미지정, 사용 불가 자료, 빈 전사와 긴 메모/회의록을 포함합니다. 기본 시안과 입력을 따로 보관합니다.

전체 흐름

  1. 새 회의 → 이름 입력 → 회의 준비. 준비를 만들 때 녹음은 시작하지 않습니다.
  2. 준비 화면에서 참석자, 참고 자료, 미리 적어둘 메모 확인 → 녹음 시작.
  3. 대화와 메모에서 전사를 읽으며 메모. 필요한 때 우측 도구를 질문으로 전환.
  4. 참고 자료 탭에서 문서를 선택해 읽고 같은 자리에서 메모하거나 질문.
  5. 녹음 종료 → 종료 확인 → 해당 회의의 회의록. 전사나 메모를 옆에 두고 정리.
  6. 초안 만들기 또는 직접 작성 → 할 일 확인 → Notion 저장 또는 회의록 복사.
  7. 저장 결과가 불확실하면 기존 결과부터 확인. 저장 후 수정한 내용은 현재 회의록 복사로 가져가기.

메모와 질문

회의 메모는 준비부터 종료까지 같은 내용입니다. 질문 답변은 근거 확인 후 회의 메모에 추가하고, 회의록에서는 메모를 참고하거나 문서에 추가합니다. 답변의 전체 내용과 근거를 함께 옮깁니다. 전사가 없어도 선택한 사용 가능한 자료로 질문할 수 있습니다.

자료함의 자료 노트는 회의와 별도로 보관합니다. 회의 메모의 자료 노트 가져오기에서 필요한 노트만 명시적으로 복사합니다. 외부 AI 정리는 자료 선택 → 전달 동의 → 요청문 복사 → 사용하는 AI에 붙여넣기 → 받은 답변 붙여넣기 → 검토 → 자료 노트 보관 순서입니다.

참석자와 자료 선택

참석자 전체를 목록으로 확인하고 이름이나 역할로 검색합니다. 모든 사람이나 그룹에서 이번 참석자를 체크합니다. 같은 사람은 한 명으로 합치고, 동명이인은 역할로 구별합니다. 보관할 때만 반영하며 취소하면 새 이름과 참석자 변경을 버립니다. 그룹 원본은 유지합니다. 새 이름 추가는 목소리 등록이나 자동 이름 식별로 취급하지 않습니다.

새 회의는 참고 자료가 비어 있습니다. 자료 선택 창의 체크는 임시 선택이며 적용을 눌렀을 때만 해당 회의에 반영합니다. 취소와 닫기는 기존 범위를 유지합니다. 전역 자료함을 탐색하는 것으로 회의 참고 범위가 바뀌지 않습니다.

시각 방향

주요 행동과 선택, 근거, 화자, 상태의 색상 역할을 나눕니다. 새 회의는 보조 버튼으로 표시합니다. 전사는 넓은 읽기 공간, 메모와 질문은 같은 보조 영역, 회의록은 본문과 참고 내용의 나란한 구성입니다. 작업 단계별 주요 행동은 준비 화면의 녹음 시작과 회의록의 보관으로 모읍니다. 로고와 모션은 보류합니다.

회의록은 읽기를 기본으로 하고 편집으로 전환해 본문과 할 일을 수정합니다. 읽기는 내용 길이만큼 표시하며 큰 고정 입력창을 사용하지 않습니다. 클릭/입력으로 화면을 다시 그려도 패널별 위치, 입력 선택과 펼친 참고 범위를 유지합니다. 회의/문서별 위치는 구분하며 새 검색과 페이지 변경은 상단에서 시작합니다.

검토 경계

상태 선택기와 대화 예시 추가는 제품 화면 밖의 검토 도구입니다. 새 회의에는 전사가 없고 검토 도구로 명시적으로 추가한 경우에만 예시를 표시합니다. 예시 초기화는 이 시안의 localStorage만 초기화합니다. 클립보드 복사는 사용자가 누른 텍스트만 복사하며 실제 외부 전송은 하지 않습니다.
