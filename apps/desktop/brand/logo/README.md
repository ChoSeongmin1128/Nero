# Nero cat logo

Selected cat symbol and custom Nero lettering, drawn as SVG paths without embedded images or font dependencies.

- `nero-logo.svg`: horizontal lockup; inline SVG inherits CSS `color`.
- `nero-logo-light.svg` / `nero-logo-dark.svg`: lockups for light and dark backgrounds.
- `nero-symbol-light.svg` / `nero-symbol-dark.svg`: standalone cat symbol.
- `nero-wordmark-light.svg` / `nero-wordmark-dark.svg`: standalone lettering.

Production assets have transparent backgrounds. Eye and nose cutouts reveal the background. Light and dark versions share identical geometry; colors are `#111111` and `#F4F4F5`.

`previews/` contains SVG presentations with explicit light/dark backgrounds, including a side-by-side comparison.

The sidebar uses the light/dark lockups. Application icons use the separately approved `../nero-cat.png`; the app does not register a separate status-bar or tray icon.
