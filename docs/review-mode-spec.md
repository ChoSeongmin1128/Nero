# 검수 모드 사양

상태: **Planned / 합의된 방향을 구체화한 구현 초안, 미구현** · 문서 버전: 0.1 · 2026-09-03

이 문서는 AI-assisted 작업 문서입니다. 사용자 합의와 현재 코드·실측을 우선해 비판적으로 읽으십시오. 문서 추가는 기능 구현·앱 교체·정답 데이터 생성 완료를 뜻하지 않습니다.

beta.8은 별도의 [화자 배정 확인 UI](transcript-library-ux.md)만 구현했습니다. 이 문서의
전체 텍스트·경계·누락 검수, 음성 해시, 교정 head와 데이터셋 스냅샷은 여전히 계획입니다.

## 목적과 범위

Grove 안에서 원음을 듣고 전사 초안을 교정하고, 나중에 검수 범위가 명확한 평가 자료로 고정할 수 있게 합니다. 일반 대화 화면과 검수 화면은 같은 교정본·명령·저장 경로를 사용합니다.

- 1차 교정은 **실제로 들리는 말을 그대로 기록**합니다. 읽기 좋게 문장 다듬기, 요약, 자동 교정, 재식별, 학습 실행은 새 기능 범위에서 제외합니다.
- 원본 음성·모델 결과는 불변입니다. 검수 진입·저장·재생으로 모델을 다시 실행하지 않습니다.
- 전사 발화와 화자 활동 구간은 별도 자료입니다. 전사 문장 경계를 RTTM 정답으로 취급하지 않습니다.
- 기존 수정문은 표시를 유지하되 용도가 미확정인 자료로 이관합니다. 검수 완료나 학습 승인으로 자동 승격하지 않습니다.
- 데이터는 로컬에 보관합니다. 학습·외부 제공 승인은 검수 완료와 별개이며, 학습 승인은 기본 미승인입니다.

계약 정본: [데이터 구조](annotation-schema.md), [한국어 라벨링](labeling-guidelines-ko.md), [내보내기](dataset-export.md).

기존 원자적 파일 쓰기를 새 검수 저장 전체의 트랜잭션/복구 검증 완료로 해석하지 않습니다.

## 화면과 조작

작은 검수 베타는 `대화 / 검수` 전환, 발화 목록, **단일 확대 파형**, 선택 발화 상세, 재생 제어, 저장 상태부터 제공합니다. 별도 다중 화자 트랙·전체/확대 파형 동시 표시·드래그 고급 편집은 후속 단계입니다.

- Pretendard와 기존 macOS 사용 흐름을 유지합니다. 화자는 이름/번호로, 검수는 텍스트/화자/시각별 상태로 표시하여 색에만 의존하지 않습니다.
- 정밀 재생은 선택한 `[start, end)`를 대상으로 하고 문맥 재생은 사용자가 설정한 앞뒤 여유를 포함합니다. 문맥 길이를 정답 경계에 더하지 않습니다.
- 파형과 목록의 선택·재생 위치는 동기화합니다. 자동 스크롤은 사용자의 탐색을 방해하지 않고 일시 정지할 수 있어야 합니다.
- 시각 숫자 입력과 키보드로도 경계를 수정합니다. 드래그를 제공할 때는 놓는 순간 한 명령으로 기록합니다.
- 입력 포커스와 한글 조합 중에는 스페이스·방향키·삭제·이동 단축키를 전사 편집기에 전달합니다. 조합 중 분할/확인/다음 항목 이동을 실행하지 않습니다.
- 필터 밖 항목까지 수정할 때 대상 개수와 범위를 먼저 보여 줍니다. 재생했다고 검수 완료되지 않습니다.

## 편집 명령·재검수·undo 계약

T=전사 텍스트, S=전사 화자 배정, B=전사 경계, A=독립 화자 활동 검수, Cₜ=전사 누락/완전성 범위, Cₐ=화자 활동/침묵 완전성 범위입니다. `재검수`는 과거 증거 삭제가 아니라 현재 내용에 대한 유효성 상실입니다.

모든 행은 **내용 변경 + 영향 검수 상태 + undo 이력**을 한 트랜잭션으로 저장합니다. 다른 층의 원값을 조용히 변경하지 않으며, 관련 없는 항목과 시간 범위는 유지합니다.

| 명령 | 변경 내용 | 재검수 범위 | undo |
|---|---|---|---|
| 실제 발화 텍스트 수정 | 선택 발화의 교정문/텍스트 역할 | 해당 T 재검수. 발화 ID·구간·제외 상태가 같으면 Cₜ 유지; 불명확/제외 상태나 발화 구성이 바뀌면 교차 범위 Cₜ 재검수. S/B/A/Cₐ는 값/의존성이 같으면 유지 | 이전 텍스트·역할·검수 증거를 함께 복원 |
| 한/선택/동일 화자 발화 배정 | 미리 확정한 모든 대상의 `speakerID` | **실제 변경된 모든 발화의 S**, 연결된 관련 범위 증거. T/B는 값이 같으면 유지 | 대상별 이전 ID와 증거 복원 |
| 경계 변경 | 해당 층의 시작/끝 tick | **old 범위 ∪ new 범위**, 그 범위의 영향 겹침 항목. 전사 층은 관련 T/S/B/Cₜ, 활동 층은 관련 A/Cₐ | 이전 경계와 영향받은 모든 증거 복원 |
| 전사 발화 추가 | 수동 출처를 가진 새 ID | 새 T/S/B 미검수, 추가 범위 및 영향 겹침의 Cₜ | 새 항목 제거, 이전 Cₜ 복원 |
| 전사 발화 삭제 | 교정본에서 비활성화, 삭제 사유·원항목 보존 | **삭제 전 범위만** Cₜ 재검수. 활동 구간과 Cₐ를 무음으로 승인하지 않음 | 원래 ID/순서/내용/검수 복원 |
| 전사 분할 | 원항목 비활성화, 새 자식 2개와 출처 연결 | 자식 T/S/B 미검수, 원구간의 Cₜ/영향 겹침 | 원항목과 자식 상태를 원복 |
| 전사 발화 병합 | 새 항목 + 모든 직접 부모/모델 원본 출처 목록 | 새 T/S/B 미검수, 병합에 포함되는 원구간·새구간·영향 겹침 Cₜ | 모든 원항목 ID·순서·내용·검수 복원 |
| 화자 실체 병합 | 중복 화자 ID를 한 ID로 명시적으로 통합 | 변경된 **모든 전사 S와 활동 A**, 관련 Cₐ/범위 증거. 숨겨진 발화도 포함 | 화자 객체·대상별 ID·증거 복원 |
| 표시 이름/회의 제목 변경 | 표시 메타데이터만 | T/S/B/A/C 전체 무효화 없음. 외부 사람 프로필 확인은 별도 | 이전 표시/프로필 메타데이터만 복원 |
| 활동 추가·삭제·경계·배정 | 독립 활동 층만 편집 | 해당 A와 old/new 영향 범위 Cₐ. 삭제는 old 범위만 | 원 활동/검수 상태 복원, 전사 원값 불변 |
| 항목 확인/불명확 표시 | 항목별 증거·사유 생성 | 선택한 축만 판정, 다른 축 승격 없음 | 이전 유효 상태 복원; 증거 사건은 감사 이력에 남김 |
| 범위 누락/침묵 검수 | Cₜ 또는 Cₐ 명시 승인 | 선택 목적·채널·정수 범위만 승인 | 이전 범위 판정 복원 |
| undo / redo | 명령 전체의 역/정방향 적용 | 해당 명령의 검수 변화도 함께 적용 | 원음·모델 출력·발행된 snapshot은 변경하지 않음 |

서로 떨어진 old/new 범위의 **합집합**을 사용하며 중간의 무관한 공백까지 하나의 큰 구간으로 무효화하지 않습니다. 넓은 검수 범위가 일부 편집과 교차하면 영향 부분을 분리해 재검수하고 나머지 부분의 근거는 보존합니다. 층 간 명시적 연결의 의존성이 바뀐 경우에만 그 연결 증거를 추가 무효화합니다.

병합은 같은 음성·채널·시간기준의 선택 항목만 대상으로 합니다. 다른 화자, 겹침, 공백을 조용히 없애지 않습니다. 모호한 병합은 거절하거나 명시적 확인과 별도 편집을 요구하며, `parentUtteranceID` 하나로 다중 출처를 축약하지 않습니다.

## 저장·복구: 첫 베타 필수

1. 현재 `correctionRevisionID`를 전제로 명령을 준비하고 범위·ID·내용·검수 의존성을 검증합니다.
2. 내용·검수·undo를 포함한 새 버전을 저장합니다. 별도 검수 파일만 먼저 갱신하지 않습니다.
3. 저장 성공 후 UI와 `저장됨` 표시를 발행합니다. 실패하면 이전 커밋/현재 표시를 유지하고 재시도 경로를 제공합니다.
4. 재시작은 마지막 유효 커밋을 복원합니다. 손상 자료를 빈 문서로 덮어쓰지 않고 원본 보존·검증 가능한 복구 후보·오류를 보여 줍니다.
5. 다른 교정 버전/모델 결과 활성화와 충돌하면 현재 입력을 잃지 않고 충돌을 알립니다. 재전사는 별도 초안이며 이전 검수본을 덮어쓰지 않습니다.

## 단계와 완료 기준

| 순서 | 범위 | 완료 기준 |
|---|---|---|
| 0. 계약 확정 | 이 네 문서, ID·시간·증거·마이그레이션·명령 fixture | 합성 사례로 변경/무효화/undo 기대값 고정, 아직 앱 기능 완료로 표기하지 않음 |
| 1. 작은 검수 베타 | 목록·단일 파형·정밀/문맥 재생·기본 전사 편집·항목 검수·JSON 백업 | 기존 문서 무손실 열기; 추가/삭제/분할/병합/경계/배정의 연속 undo; 한글 조합 검증; 저장 실패/중단/재시작 복구; JSON round-trip; 표시 경계와 실제 재생 오차 측정 |
| 2. 평가 자료 생성 | 독립 활동 편집·완전성 범위 검수·불변 snapshot·TSV/RTTM/UEM | 검수 침묵 포함, 누락/겹침/제외 사유 재현, 미검수 정답 유입 차단, CER/DER/종합 지표 재현 |
| 3. 고급 작업 | 다중 화자 트랙·대량 조작·모델별 학습 변환 | 새 회의 holdout으로 검증, 모델별 라이선스/승인/분할 누수 검사; 별도 구현 승인 |

첫 베타에 저장 안정성을 뒤로 미루지 않습니다. 반복 사용한 개인 3분 파일은 개발/회귀 자료이며 새 정확도 holdout으로 세지 않습니다. 편집 응답 100ms는 **측정 전 목표**일 뿐 성능 보장이 아닙니다. 긴 파일의 파형 생성·캐시는 백그라운드·구간 단위로 검증합니다.
