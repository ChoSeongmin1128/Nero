# 전사 모델 선택

이 문서는 현재 소스의 동작을 설명한다. 배포된 버전은 릴리스 안내를 확인한다.

초기 설정 또는 설정 > 음성 인식 > 전사 모델에서 선택한다. Apple Silicon/macOS 26 이상에서는 다음 세 가지를 제공한다.

| 선택 | 처리 방식 |
| --- | --- |
| MOSS (기본/추천) | 녹음 종료 후 60초 단위로 처리한다. 별도 모델을 준비해야 하며 CPU/GPU와 메모리를 사용한다. 저자원 또는 모든 입력에서 더 좋은 품질을 보장하지 않는다. |
| Qwen3-ASR 한국어 (실험적) | 사용자가 명시적으로 선택하고 준비한 경우에만 사용한다. 전사/정렬 모델을 사용하며 CPU/GPU와 메모리 부담이 클 수 있다. 16GB 이상에서도 다른 앱이 느려질 수 있어 준비 전에 확인한다. |
| macOS 기본 전사 | Nero 전용 전사 모델을 설치하지 않는다. 시스템 한국어 언어 데이터가 필요할 수 있으며 녹음 종료 후 처리한다. |

Qwen은 Nemotron 미리보기 모델을 요구하지 않는다. MOSS/Qwen/macOS 전사에서는 녹음 중 인식 미리보기 대신 녹음 종료 후 전사한다. 화자 구분은 별도로 선택하며, 켜면 독립적인 Nemotron 3 화자 모델을 준비한다. 화자 구분이 실패해도 먼저 저장한 전사와 원음은 보존한다.

신규 Mac 설정의 기본/추천은 MOSS다. 메모리 크기에 따라 Qwen을 자동 추천하거나 선택하지 않는다. 기존 사용자 선택과 진행/대기 작업의 동결된 엔진은 임의로 바꾸지 않는다. 기존 사용자에게 MOSS 전환을 안내하며 사용자가 확인해야 준비/전환한다. 준비 중에는 현재 모델을 유지하고 준비 완료와 작업 종료 후 전환한다. 준비된 모델도 전환 확인을 거친다. 다운로드/전환 취소와 실패는 현재 선택을 보존하고 자동 재시도하지 않는다. 기존 회의를 자동 재처리하지 않으며 다른 엔진으로 조용히 대체하지 않는다.

Windows는 지원되는 대체 실행기가 준비될 때까지 기존 Nemotron/Whisper Turbo를 유지한다. Mac 정책을 Windows에 적용해 전사를 막거나 모델을 삭제하지 않는다.

## 부분 결과와 재시도

MOSS의 새 제품 경로는 `moss-independent-chunks-v1`이다. 각 구간은 정확한 입력 프레임/해시, 원본 출력, EOS와 실제 생성 예산, 음향 특징 범위를 검증한다. 실패한 구간 뒤의 정상 구간도 보존하고, 누락 범위를 화면과 AI 입력에 전달한다. 부분 결과는 완료로 숨기지 않으며 작업 목록에서 실패/미처리 구간만 명시적으로 재시도한다. 앱을 다시 열어도 검증된 정상 구간을 재사용한다. 그 사이 편집한 전사는 덮어쓰지 않고 새 결과를 별도 이력으로 보존한다.

고정 모델/런타임의 10ms 시각 표현에서 검증된 최대 20ms(16kHz 입력의 320프레임) 끝점 초과는 `moss-independent-chunks-projector-v2`가 해당 구간/원음의 실제 끝으로만 보정한다. 예를 들어 원시 결과 `59.50~60.02초`는 보존하고 표시/재생에는 `59.50~60.00초`를 사용한다. 마지막 짧은 구간도 실제 입력 길이를 기준으로 하며 시작 시각과 본문을 유지한다. 원시 출력 해시, 처리 버전과 `normalizedEndSegments`로 보정된 발언을 추적한다.

이 범위의 정상 보정만으로 경고/재시도/검토 필요 상태를 만들지 않는다. 별도 화자 분석은 보정된 발언 범위에 기존 활동 비율/겹침 검사를 적용한다. 이 보정은 단어 단위 강제 정렬을 의미하지 않는다. 더 큰 초과, 시간 역전, 보정 뒤 유효한 범위가 없는 결과, 손상된 입력과 거짓 완료 근거는 해당 구간 실패로 남긴다. 원래부터 길이가 0인 발언은 구간 문맥으로 유지하며 정확한 재생/자동 화자 근거로 쓰지 않는다. 이미 저장된 v1 문맥 투영과 whole-recording MOSS 기록은 기존 계약으로 읽고 자동 변경하지 않는다.

## 이전 파일 정리

지원되는 새 모델의 준비와 명시적 전환이 끝나면 Mac에서 Nemotron ASR, Whisper Turbo, Whisper large-v3의 불필요한 가중치/부분 다운로드/공식 격리 파일/검증 표시를 정리한다. MOSS, 설치된 Qwen, Nemotron 3 화자 모델, 요약 모델, 시스템 언어 데이터와 공통 실행기는 정리 대상이 아니다. 진행/대기/재시도 가능한 작업이 참조하면 보류한다. 과거 정리 계획에 Qwen이 들어 있어도 새 정책에서 삭제하지 않는다.

정리 계획은 `preferences/speech-model-retirement.json`에 저장하며 재시작 후 현재 선택/준비/작업을 다시 확인한다. 정리 실패는 새 엔진 실패와 구분한다. 설정의 '다시 정리'는 파일 정리만 수행한다. 대체 엔진이 없거나 준비/전환이 끝나지 않으면 기존 파일을 지우지 않는다.

## 회의 용어집

회의 자료의 Notion 문서에서 후보 표기를 확인하고 사용자가 승인한 용어만 저장한다. 같은 자료를 연결한 다른 회의의 승인 표기도 명시적으로 가져올 수 있다. 자료를 읽거나 새로고침했다는 이유로 후보가 자동 승인되지는 않는다.

전사 작업과 녹음 세션은 시작할 때 용어집을 고정한다. 이후 용어집 변경은 진행 중인 작업이나 과거 원문을 바꾸지 않는다. 녹음 시작 때 고정에 실패하면 녹음은 계속하고, 이어 녹음하거나 녹음을 마칠 때 그 시점의 용어집으로 고정한다. Whisper는 승인 용어의 제한된 묶음을 초기 문맥으로 사용한다. Nemotron과 macOS 기본 전사에는 지원하지 않는 프롬프트를 전달하지 않는다. 기존 선택적 용어 교정 기능과 원문 저장은 별도이며, 용어집이 자동 치환 규칙이나 화자 이름 배정으로 바뀌지는 않는다.

## 연구용 후보 평가

Nemotron Mini 64e와 Gemma/Qwen 후보정 모델은 [별도 평가 도구](../scripts/model-evaluation/README.md)에서 비교할 수 있는 연구 후보다. Qwen3-ASR 한국어의 평가 경로와 제품에서 지원하는 선택 경로도 구분한다. 평가 도구에 있는 모델이 앱의 선택 목록에 자동 추가되지는 않는다. 전사 모델, 화자 출력과 후보정 모델을 서로 다른 단계로 평가하며 모델 크기만으로 한국어 품질이나 기기 지원을 확정하지 않는다.

MOSS의 기존 whole-recording 결과와 headless 평가 실행기는 새 제품 구간 경로와 별도로 보존한다. 60초 단위의 진단 실행은 녹음 전체를 하나의 decoder generation으로 처리하는 저장 계약과 다르며, 같은 익명 화자 번호를 구간 사이의 동일 인물로 연결하지 않는다. 평가의 프로세스 종료, 입력 특징 처리 범위와 출력 완전성 검증, 제품 저장 수용은 각각 구분한다.

평가 실행기와 보고서 준비, 합성 테스트 통과, 실제 모델/자료 준비 및 실측 완료는 각각 다른 상태다. 도구는 모델과 런타임을 자동 다운로드하거나 설치하지 않는다. 설정한 경로와 준비 상태를 검사한 뒤 실제 실행을 명시적으로 시작한다.
