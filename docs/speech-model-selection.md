# 전사 모델 선택

이 문서는 현재 소스의 동작을 설명한다. 배포된 버전은 릴리스 안내를 확인한다.

초기 설정과 설정의 음성 처리 모델에서 엔진을 선택한다. 추천 표시는 기기의 운영체제, 물리 메모리와 해당 실행기의 지원 여부를 사용한다. 추천만으로 기존 선택을 바꾸거나 모델을 다운로드하지 않는다. 선택과 준비는 사용자가 실행하며 기존 회의를 자동 재처리하지 않는다.

이미 쓰고 있는 모델이 준비된 상태에서 아직 받지 않은 모델을 고르면, 받을 크기를 보여 주고 확인을 받은 뒤 내려받는다. 받는 동안에는 기존 모델로 녹음과 전사를 계속하고, 필요한 파일이 모두 준비되고 진행 중인 녹음과 처리 작업이 없을 때 선택을 바꾼다. 대기 중인 전환은 `preferences/speech-switch.json`에 두고 `preferences/speech.json`은 전환하는 순간에만 바뀐다. 다운로드를 취소하거나 전환을 취소하면 기존 모델을 그대로 쓴다. 앱을 다시 열면 받은 부분을 이어받을 수 있고, 자동으로 다시 받지 않는다.

준비된 모델을 쓰는 기존 사용자에게는 새로 추천하는 모델(현재 Qwen3-ASR 한국어)을 한 번 안내한다. 받을 크기, 녹음 후 늘어나는 대기 시간, 기존 회의가 바뀌지 않는다는 점을 보여 주고, 사용자가 고른 결과를 `preferences/speech-offers.json`에 남긴다. 창을 닫기만 하면 결정으로 기록하지 않는다.

| 선택 | 지원 환경 | 용도 |
| --- | --- | --- |
| Nemotron 3.5 | 지원되는 Mac/Windows | 기본 녹음 중 전사 |
| Qwen3-ASR 한국어 | 지원되는 Apple Silicon Mac | 녹음 중에는 Nemotron 미리보기, 녹음 후 한국어 모델로 다시 전사해 저장 |
| Whisper large-v3-turbo Q5 | 지원되는 Mac/Windows | 속도와 정확도 균형 |
| Whisper large-v3 Q5 | 지원되는 Apple Silicon Mac | 처리 시간보다 정확도를 우선하는 추가 선택 |
| macOS 기본 전사 | 지원되는 Apple Silicon/macOS 26 이상 | Nero 전용 전사 모델 없이 시스템 음성 인식 사용 |

Whisper large-v3 Q5 파일은 약 1.08 GB다. 고정된 리비전, 파일 크기와 SHA-256을 검증해 준비하고, Turbo와 구분된 모델 경로와 원본 출처를 보존한다. 두 모델은 같은 실행기를 사용하지만 출력의 모델 구조도 각각 검사한다. 실행 실패 시 다른 모델로 자동 전환하지 않는다.

Apple Silicon Mac의 물리 메모리가 16 GiB 이상이면 지원되는 large-v3를 정확도 우선 선택으로 추천한다. 이 기준은 OpenAI의 원본 large 모델 메모리 안내에 앱과 시스템의 여유를 더한 제품 정책이며, Q5의 실측 최소 요구량이나 Nemotron 대비 한국어 정확도 우위를 뜻하지 않는다. 8 GiB 이하에서 시스템 전사를 사용할 수 있으면 이를 추천하고, 그 외에는 지원되는 기본 모델을 추천한다. 메모리를 확인하지 못하면 고사양으로 추정하지 않는다.

Qwen3-ASR 한국어는 음성 인식 GGUF(약 2.8 GB)와 단어 시각 정렬 GGUF(약 0.99 GB)를 쓰고, 녹음 중 미리보기용 Nemotron 3.5 모델을 함께 준비한다. 두 GGUF는 고정 저장소, 리비전, 크기와 SHA-256으로 검증한다. 실행기는 고정 커밋에서 빌드한 CrispASR CLI다. Apple Silicon Mac의 물리 메모리가 16 GiB 이상이면 이 모델을 추천한다. 16 GiB 미만이거나 메모리를 확인하지 못하면 선택은 그대로 허용하고, 모델 준비 전에 측정 피크(약 4.5 GB)와 기기 메모리로 계산한 경고를 보여 주며 사용자가 확인란을 선택해야 준비할 수 있다. 이 확인은 저장하지 않는다. 경고는 측정값에 근거한 안내이며 실행 가능 여부를 판정하지 않는다.

화자 구분은 전사 모델과 별도로 선택한다. 화자 구분을 끄면 전사만 실행한다. 특정 전사 모델을 선택했다고 참석자 계정이나 목소리 신원이 자동 확인되지는 않는다.

## 회의 용어집

회의 자료의 Notion 문서에서 후보 표기를 확인하고 사용자가 승인한 용어만 저장한다. 같은 자료를 연결한 다른 회의의 승인 표기도 명시적으로 가져올 수 있다. 자료를 읽거나 새로고침했다는 이유로 후보가 자동 승인되지는 않는다.

전사 작업과 녹음 세션은 시작할 때 용어집을 고정한다. 이후 용어집 변경은 진행 중인 작업이나 과거 원문을 바꾸지 않는다. 녹음 시작 때 고정에 실패하면 녹음은 계속하고, 이어 녹음하거나 녹음을 마칠 때 그 시점의 용어집으로 고정한다. Whisper는 승인 용어의 제한된 묶음을 초기 문맥으로 사용한다. Nemotron과 macOS 기본 전사에는 지원하지 않는 프롬프트를 전달하지 않는다. 기존 선택적 용어 교정 기능과 원문 저장은 별도이며, 용어집이 자동 치환 규칙이나 화자 이름 배정으로 바뀌지는 않는다.

## 연구용 후보 평가

Nemotron Mini 64e, MOSS, TeamUNIVA Qwen3-ASR 한국어판과 Gemma/Qwen 후보정 모델은 [별도 평가 도구](../scripts/model-evaluation/README.md)에서 비교할 수 있는 연구 후보다. 앱의 모델 선택 목록에 자동 추가되지 않는다. 전사 모델, 화자 출력과 후보정 모델을 서로 다른 단계로 평가하며 모델 크기만으로 한국어 품질이나 기기 지원을 확정하지 않는다.

평가 실행기와 보고서 준비, 합성 테스트 통과, 실제 모델/자료 준비 및 실측 완료는 각각 다른 상태다. 도구는 모델과 런타임을 자동 다운로드하거나 설치하지 않는다. 설정한 경로와 준비 상태를 검사한 뒤 실제 실행을 명시적으로 시작한다.
