# 첫 실행과 연결

## 설치와 모델 준비

[Releases](https://github.com/ChoSeongmin1128/Nero/releases)에서 운영체제에 맞는 파일을 받으세요.
macOS는 Apple Silicon과 macOS 26 이상을 지원하며, Windows는 x64 설치 파일을 사용합니다.
macOS에서는 DMG를 열어 Nero를 응용 프로그램 폴더로 옮긴 뒤 실행합니다.
Windows에서는 설치 프로그램을 실행합니다. 기본 설치는 현재 사용자에게 적용됩니다.

Nero 실행 후 모델 준비 화면의 안내를 따르세요. 기본 음성 인식은 Nemotron 3.5,
화자 구분은 별도의 Nemotron 3 모델을 사용합니다. 필요한 모델은 앱에서 내려받고 검증합니다.
실행 엔진은 설치 파일에 포함되어 있어 Python, Homebrew나 별도의 모델 서버가 필요하지 않습니다.
최초 다운로드에는 인터넷과 모델 파일을 보관할 저장 공간이 필요합니다.

모델 준비가 중단되면 앱에서 다시 시도하세요. 이미 검증된 모델은 호환되는 업데이트에서 재사용합니다.
준비가 끝나지 않은 기능에는 앱에서 이유와 다음 동작을 안내합니다.

## 첫 녹음과 파일 가져오기

1. **새 회의**에서 제목과 메모를 준비하거나 **녹음 시작**으로 바로 시작합니다.
2. 녹음할 마이크를 확인하고 운영체제의 접근 요청을 허용합니다.
3. 녹음 중에는 일시 정지와 재개를 사용할 수 있습니다. 녹음을 멈추면 저장된 오디오의 처리가 이어집니다.
4. 음성 기록에서 시간을 눌러 원음을 듣고, 본문과 화자 이름을 수정합니다.

현재는 선택한 마이크를 녹음합니다. 회의 서비스에 봇으로 참석하거나 시스템 출력을 직접 녹음하지 않습니다.
기존 파일은 앱의 가져오기 기능으로 선택합니다. Windows에서는 WAV 가져오기를 지원합니다.
처리 속도는 하드웨어와 입력 길이에 따라 달라집니다.

## 회의 요약

설정에서 선택 기능인 **회의 요약**을 추가하고 모델을 준비하세요.
음성 기록이 있는 회의에서 템플릿을 선택하고 **요약하기**를 누릅니다.
내장 요약은 로컬 Gemma 모델로 처리합니다. 원음, 메모, 전사와 이전 요약은 별도로 보존합니다.
생성 결과는 초안으로 검토하고, 중요한 내용은 원문과 대조하세요.

## Google Calendar

설정의 연결 화면에서 Google Calendar를 선택하고 브라우저에서 본인의 계정으로 승인합니다.
연결한 캘린더의 일정을 선택해 회의를 준비할 수 있습니다. 연결은 선택 사항이며 일반 녹음에 필요하지 않습니다.
로그인이 중단되면 앱에서 취소하거나 다시 연결하세요. 브라우저가 열리지 않았을 때는 진행 중인 인증 창을 다시 열 수 있습니다.
연결을 해제해도 저장된 회의를 삭제하지 않습니다.

## AI 도구 연결

설정에 표시되는 지원 도구에서 **연결**을 누르고 해당 도구의 설치/승인 화면을 완료하세요.
Nero의 연결 화면에서 연결 상태와 업데이트 필요 여부를 확인할 수 있습니다.
로컬 연결은 회의 검색, 음성 기록 확인과 명시적으로 요청한 회의 변경에 사용됩니다.
상세 지원 범위는 [로컬 에이전트 연결](local-agent.md)을 확인하세요.

조회 도구는 저장된 회의를 읽으며 녹음이나 모델 실행을 자동 시작하지 않습니다.
연결한 AI 도구가 읽은 내용은 그 도구의 처리 정책을 따릅니다. 공개가 곤란한 회의는 연결 전에 확인하세요.

## 업데이트와 제거

설정에서 앱 업데이트를 확인하세요. 새 파일을 받은 뒤 앱의 재시작 안내에 따라 설치합니다.
녹음, 처리와 저장 중인 편집이 끝나야 설치할 수 있습니다.

Windows의 기본 앱 제거는 회의 데이터와 모델을 보존합니다. 제거 화면에서 앱 데이터 삭제를
선택하면 원음과 기록까지 삭제되므로 보관 여부를 먼저 확인하세요.
별도로 설치한 AI 도구 연결은 해당 도구에서 해제해야 합니다.
자세한 동작과 복구 방법은 [업데이트 안내](app-updates.md)를 참고하세요.
