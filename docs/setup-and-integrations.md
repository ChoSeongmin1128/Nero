# 첫 실행과 연결

## 설치와 모델 준비

[Releases](https://github.com/ChoSeongmin1128/Nero/releases)에서 운영체제에 맞는 파일을 받으세요.
macOS는 Apple Silicon과 macOS 26 이상을 지원하며, Windows는 x64 설치 파일을 사용합니다.
macOS에서는 DMG를 열어 Nero를 응용 프로그램 폴더로 옮긴 뒤 실행합니다.
Windows에서는 설치 프로그램을 실행합니다. 기본 설치는 현재 사용자에게 적용됩니다.

초기 설정 또는 **설정 > 녹음 > 음성 처리 모델**에서 모델을 선택하세요.

| 모델 | 처리 방식과 선택 기준 |
| --- | --- |
| Nemotron 3.5 (기본) | 녹음 중 음성을 연속해서 처리하는 기본 모델입니다. |
| Whisper large-v3-turbo | Nemotron과 인식 결과가 다를 수 있는 대안입니다. 기기에 따라 녹음 종료 후 처리 시간이 더 필요할 수 있습니다. |

모델별 속도와 인식 결과는 기기, 언어와 녹음 환경에 따라 달라집니다.
선택한 음성 인식 모델과 공통 화자 구분 모델(Nemotron 3)을 앱에서 내려받고 검증합니다.
두 음성 인식 모델을 모두 다운로드할 필요는 없습니다.
실행 엔진은 설치 파일에 포함되어 있어 Python, Homebrew나 별도의 모델 서버가 필요하지 않습니다.
최초 다운로드에는 인터넷과 모델 파일을 보관할 저장 공간이 필요합니다.

녹음이나 처리가 진행 중이면 끝난 뒤 모델을 변경하세요.
선택은 이후 새로 시작하는 처리에 적용되며 기존 회의는 자동으로 다시 처리하지 않습니다.
기존 작업의 재시도는 해당 작업에 저장된 모델을 유지합니다.
다른 모델로 기존 회의를 다시 처리하려면 모델을 준비한 뒤 회의의 **다시 변환**을 사용하세요.

모델 준비가 중단되면 앱에서 다시 시도하세요. 이미 검증된 모델은 호환되는 업데이트에서 재사용합니다.
준비가 끝나지 않은 기능에는 앱에서 이유와 다음 동작을 안내합니다.

## 첫 녹음과 파일 가져오기

1. **새 회의**에서 제목과 메모를 준비합니다.
2. 녹음할 마이크를 확인하고 운영체제의 접근 요청을 허용합니다.
3. 녹음 중에는 일시 정지와 재개를 사용할 수 있습니다.
4. 녹음이 끝나면 준비된 음성 기록을 확인하고, 시간을 눌러 원음을 듣거나 본문과 화자 이름을 수정합니다.

현재는 선택한 마이크를 녹음합니다. 회의 서비스에 봇으로 참석하거나 시스템 출력을 직접 녹음하지 않습니다.
기존 파일은 새 회의의 **음성 가져오기**로 선택합니다. macOS와 Windows에서 WAV, M4A, MP3, AAC, AIFF, CAF, FLAC, Ogg를 선택할 수 있습니다. 파일 내부 인코딩의 지원 범위는 [음성 파일 가져오기](audio-import.md)를 확인하세요.
처리 속도는 하드웨어와 입력 길이에 따라 달라집니다.

## 회의 탐색과 메모

사이드바에서 전체 목록, 폴더, 휴지통과 최근 회의를 확인합니다.
사이드바를 접으면 네 항목의 아이콘이 남으며, 마우스를 올리면 해당 목록이 오른쪽에 열립니다.
최근 회의는 접거나 목록 안에서 스크롤할 수 있습니다.
이전/다음, 사이드바 열기와 새 회의는 앱 상단에 있습니다. 알림은 사이드바 상단에서 확인합니다. 휴지통 미리보기에서도 비우기 아이콘을 사용할 수 있습니다.

요약과 음성 기록은 같은 본문에 표시됩니다. **메모**를 열어 함께 작성하고,
경계를 드래그해 메모 영역의 너비를 조절할 수 있습니다.

## 참석자

회의의 **참석자**에서 사람이나 그룹을 검색해 추가하거나 임시 참석자를 만드세요.
녹음 중이나 끝난 뒤에도 변경할 수 있습니다.
저장한 사람과 그룹은 **설정 > 참석자**에서 관리합니다.
참석자 이름이 음성만으로 자동 식별되는 것은 아닙니다.

## 회의 요약

**설정 > 일반**에서 선택 기능인 **회의 요약**을 추가하고 모델을 준비하세요.
음성 기록이 있는 회의에서 템플릿을 선택하고 **요약하기**를 누릅니다.
내장 요약은 로컬 Gemma 모델로 처리합니다. 원음, 메모, 음성 기록과 이전 요약은 별도로 보존합니다.
생성 결과는 초안으로 검토하고, 중요한 내용은 원문과 대조하세요.

**설정 > 요약 템플릿**에서 기본 템플릿을 수정하거나 삭제하고 새 템플릿을 추가할 수 있습니다.
**전체 초기화**는 기본 템플릿을 복원하고, 직접 추가한 템플릿과 수정 내용을 지웁니다.
기존 회의에 저장된 요약은 바뀌지 않습니다.

## Google Calendar

**설정 > 연동**에서 Google Calendar를 연결하고 브라우저에서 본인의 계정으로 승인합니다.
빈 회의의 **일정 연결**에서 날짜와 일정을 선택하면 제목과 회의 날짜가 채워집니다.
과거나 미래 일정도 날짜를 바꿔 선택할 수 있습니다. Nero가 실행 중이면 선택한 캘린더의 회의를 시작 5분 전에 알립니다.
연결은 선택 사항이며 일반 녹음에 필요하지 않습니다.
로그인이 중단되면 앱에서 다시 시도하세요. 브라우저가 열리지 않았을 때는 진행 중인 인증 창을 다시 열 수 있습니다.
연결을 해제해도 저장된 회의를 삭제하지 않습니다.

## AI 도구 연결

**설정 > 연동**에서 Claude나 ChatGPT의 **연결**을 누르고 해당 도구의 설치/승인 화면을 완료하세요.
Nero의 연결 화면에서 연결 상태와 업데이트 필요 여부를 확인할 수 있습니다.
로컬 연결은 회의 검색, 음성 기록 확인과 명시적으로 요청한 회의 변경에 사용됩니다.
다른 도구에는 **연결 프롬프트**를 열어 안내된 내용을 붙여넣을 수 있습니다.
상세 지원 범위는 [로컬 에이전트 연결](local-agent.md)을 확인하세요.

조회 도구는 저장된 회의를 읽으며 녹음이나 모델 실행을 자동 시작하지 않습니다.
연결한 AI 도구가 읽은 내용은 그 도구의 처리 정책을 따릅니다. 공개가 곤란한 회의는 연결 전에 확인하세요.

## 업데이트와 제거

앱은 새 업데이트를 자동으로 확인하고 다운로드합니다. 준비되면 사이드바 하단의 **업데이트**를 눌러 다시 시작하세요.
사이드바가 접혀 있으면 같은 위치에 아이콘으로 표시됩니다. 수동 확인은 **설정 > 일반**에서 할 수 있습니다.
녹음, 처리와 저장 중인 편집이 끝나야 설치할 수 있습니다.

Windows의 기본 앱 제거는 회의 데이터와 모델을 보존합니다. 제거 화면에서 앱 데이터 삭제를
선택하면 원음과 기록까지 삭제되므로 보관 여부를 먼저 확인하세요.
별도로 설치한 AI 도구 연결은 해당 도구에서 해제해야 합니다.
자세한 동작과 복구 방법은 [업데이트 안내](app-updates.md)를 참고하세요.
