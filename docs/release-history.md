# 릴리스 안내

배포 버전별 설치 파일, 사용자 변경 사항과 알려진 제약은
[GitHub Releases](https://github.com/ChoSeongmin1128/Nero/releases)에서 확인하세요.

첫 공개 지원 기준은 `v0.0.1`입니다. 각 릴리스의 태그와 설치 파일에 포함된
`build-info.json`이 배포 소스와 빌드 번호의 기준입니다.

## 0.3.0

- 요약과 음성 기록을 한 본문에서 읽고 메모 영역의 너비를 조절할 수 있습니다.
- 축소 사이드바에 전체 목록, 폴더, 휴지통과 최근 회의를 유지하고 해당 목록을 미리 볼 수 있습니다.
- 참석자와 그룹, 요약 템플릿을 관리하고 Claude/ChatGPT에서 회의를 활용할 수 있습니다.
- 두 운영체제의 음성 파일 가져오기 형식을 확장하고 Windows의 Whisper 실행을 개선했습니다.
- 새 버전을 자동으로 확인하고 다운로드하며 사이드바에서 업데이트할 수 있습니다.

설치 파일과 배포 소스는 [v0.3.0](https://github.com/ChoSeongmin1128/Nero/releases/tag/v0.3.0)에서 확인하세요.
