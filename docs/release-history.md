# Nero 릴리스 이력

제품 버전, 소스 커밋과 실제 배포 상태를 구분한다. 전체 Git 변경 이력은 저장소에 유지하고, 이 문서에는 릴리스 기준과 주요 경계를 기록한다. 버전 규칙은 [버전 관리](versioning.md)를 따른다.
