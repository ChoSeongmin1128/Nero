## 0.0.4 (빌드65)

macOS용 업데이트입니다. Windows의 기존 설치/업데이트 경로는 별도로 유지합니다.

- 0.0.3에서 모델을 내려받거나 확인하기 시작하면 앱이 종료되던 문제를 수정했습니다. 중단된 다운로드는 설정에서 다시 시도하면 받은 부분부터 이어받습니다.

- 회의 이동, 휴지통 비우기 같은 변경 뒤 회의 목록과 폴더가 비어 보이다가 앱을 다시 열어야 돌아오던 문제를 수정했습니다.

- 요약의 근거 버튼이 발언 시각(예: 12:34)을 표시합니다. 시각을 정할 수 없는 발언은 기존처럼 번호로 표시합니다.

- 전사 방식을 직접 고르지 않고 기존 기본값으로 쓰던 사용자는 업데이트 후에도 기존 전사 모델을 그대로 사용합니다. 다른 전사 모델에서 macOS 기본 전사로 바꿀 때 준비가 바로 실패하던 문제와 MOSS 전환 안내의 수락 기록을 바로잡았습니다.

## 0.0.3 (빌드64)

macOS용 업데이트입니다. Windows의 기존 설치/업데이트 경로는 별도로 유지합니다.

- 네이티브 화면 구성, 공통 아이콘, 사이드바와 네로 패널, 음성 기록/요약의 밀도와 출처 이동을 정리했습니다. 대화 기록, 회의 첨부, 입력 자동 높이와 전송 동작도 개선했습니다.

- 지원 Mac의 신규 기본 전사는 MOSS입니다. Qwen 한국어는 명시적으로 선택하는 실험적 옵션이며, 별도 전사 모델을 원치 않으면 macOS 기본 전사를 선택할 수 있습니다. 기존 선택과 진행 중 작업은 보존합니다. MOSS는 정상 구간을 먼저 저장하고 실패 구간만 다시 시도하며, 작은 끝점 오차는 원시 결과를 보존한 채 재생 범위만 보정합니다.

- 네로 패널이나 연동 설정을 열 때 기존 AI 로그인을 자동 확인합니다. 같은 화면이 열린 채 앱으로 돌아올 때도 확인하며, 반복 클릭 없이 저장된 계정을 복원합니다. 실제 로그인이나 실행기 설치는 사용자가 시작합니다.

- 음성 처리 모델의 중복 전환 요청과 취소/재시작 처리를 보완합니다. 대체 모델의 준비와 전환이 끝나면 더 이상 사용하는 작업이 없는 이전 전사 모델 파일을 정리하며, 화자 모델과 공유 실행기는 유지합니다. 정리에 실패하면 현재 모델은 계속 사용하고 설정에서 파일 정리만 다시 시도할 수 있습니다.

- 일정 시작 시각이 되면 알림의 녹음 시작 버튼이 눌리지 않던 문제를 수정합니다. 알림이 표시되는 동안 시작할 수 있으며, 처리 중 중복 클릭과 오류 후 재시도를 함께 확인했습니다.

- Qwen 한국어 전사 모델을 선택할 때 메모리가 16GB 이상이어도 CPU/GPU와 메모리 사용으로 다른 앱이 느려질 수 있음을 안내합니다. 16GB 미만에서 모델 준비 전 받는 추가 확인은 유지합니다.

## 0.0.2 (빌드63)

macOS용을 먼저 공개합니다. Windows는 0.0.1(빌드62)을 계속 사용하며, Windows용은 따로 공개합니다.

- Mac에서 녹음이 끝난 뒤 한국어 Qwen3-ASR 모델로 최종 음성 기록을 만듭니다. 녹음 중 실시간 미리보기와 화자 구분은 기존 모델을 사용합니다. 처음 전환할 때 음성 인식 모델(약 2.8GB)과 단어 시각 정렬 모델(약 0.9GB)을 내려받으며, 메모리가 16GB 미만이면 경고를 확인한 뒤 진행합니다.
- 긴 녹음에서 마지막 단어 시각이 녹음 길이를 넘어 음성 기록이 저장되지 않던 문제를 수정했습니다.
- 음성 파일을 창에 끌어다 놓아 가져올 수 있습니다. 이미 음성이 있는 회의에 놓으면 새 회의로 가져옵니다.
- AI 대화가 화면에 열린 회의를 따라가며, 보낸 질문을 고치면 이전 질문과 답변을 버전으로 남깁니다. 대화 목록과 휴지통에서 대화를 정리할 수 있고, 모델 선택 메뉴에서 모델을 검색할 수 있습니다.
- 회의 상단의 요약과 음성 기록 버튼을 한 묶음으로 정리했고, 스크롤하면 지금 읽는 쪽이 표시됩니다. 더보기 메뉴에서 녹음 파일을 내보낼 수 있습니다.
- 일정 알림이 회의 시작 5분 후까지 남아 있어 그동안 녹음을 시작할 수 있습니다. 녹음 제어창의 여백과 표시를 정리했습니다.
- Google 참석자를 사람별로 가져오고, Google Calendar 연결이 끊기면 다시 연결하도록 안내합니다. 접근 토큰이 한 번 거부되면 새로 받아 다시 시도합니다.
- Claude와 ChatGPT에서 사용할 수 있는 Nero 기능이 늘었습니다(MCP 도구 70개). 연동은 앱의 MCP 연결 설정에서 업데이트합니다.
- 업데이트 확인을 macOS와 Windows가 따로 합니다.

### 기존 기능

최종 배포 소스와 빌드 번호는 설치 파일에 포함된 `build-info.json`과 영수증으로 확인합니다.

- 요약과 음성 기록을 한 본문에서 읽고 메모 영역의 너비를 조절할 수 있습니다.
- 이전/다음, 사이드바 열기와 새 회의를 상단 도구에서 사용할 수 있습니다. 알림은 사이드바 내부 상단에 있습니다.
- 축소 사이드바의 전체 목록, 폴더, 휴지통과 최근 회의에서 해당 목록을 미리 볼 수 있습니다. 최근 회의는 목록 안에서 독립적으로 스크롤합니다.
- 폴더와 최근 회의의 더보기 버튼 위치와 클릭 영역을 통일했습니다.
- Mac의 화면 이동/사이드바/새 회의 도구는 창 제목 표시줄에 통합되며 전체 화면에 맞춰 정렬됩니다.
- 휴지통 미리보기에서도 휴지통을 비울 수 있습니다. 본문의 휴지통 비우기와 같은 확인 흐름을 사용합니다.
- 참석자와 그룹, 요약 템플릿을 관리하고 Claude/ChatGPT에서 회의를 활용할 수 있습니다.
- 두 운영체제에서 여러 음성 파일 형식을 가져오고 Windows에서 Whisper를 사용할 수 있습니다.
- 새 버전을 자동으로 확인하고 다운로드하며 사이드바와 CLI/MCP에서 업데이트할 수 있습니다.
- 앱 내 자동 요약은 품질 개선을 위해 일시 중지했습니다. 기존 요약 확인과 Claude/ChatGPT 요약 저장은 사용할 수 있습니다.
- 고샘플레이트/다채널의 긴 녹음도 원본을 보존하면서 재생용 파일을 변환합니다.
- 설정에서 개인정보처리방침을 확인할 수 있으며 배포 구성 요소의 라이선스 고지를 함께 제공합니다.
- 화면 자산과 음성 처리 실행 파일의 중복 포함, 회의 상태와 폴더 집계의 반복 작업을 줄였습니다.

CLI/MCP 연결 패키지의 세대는 제품 버전과 별개인 `0.3.0-nero.39`입니다.
