# Nero 릴리스 이력

제품 버전, 소스 커밋과 실제 배포 상태를 구분한다. 전체 Git 변경 이력은 저장소에 유지하고, 이 문서에는 릴리스 기준과 주요 경계를 기록한다. 버전 규칙은 [버전 관리](versioning.md)를 따른다.

## 0.0.1 / build 35 (개인 설치 및 화면 검증 완료)

- 실제 앱에 단일 새 회의 동작, 회의 내부의 일정/음성 연결과 빈 회의 메모를 적용했다. 제목/메모/폴더는 보존하며 현재 draft 버전을 검증한다. 저장 후 디렉터리 동기화 오류가 나더라도 이미 저장된 결과를 메모리에 반영해 오래된 재시도가 덮어쓰지 못한다.
