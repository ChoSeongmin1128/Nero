# 릴리스 안내

배포 버전별 설치 파일, 사용자 변경 사항과 알려진 제약은
[GitHub Releases](https://github.com/ChoSeongmin1128/Nero/releases)에서 확인하세요.

## 0.0.1 (빌드58)

최종 배포 소스와 빌드 번호는 설치 파일에 포함된 `build-info.json`과 영수증으로 확인합니다.

- 요약과 음성 기록을 한 본문에서 읽고 메모 영역의 너비를 조절할 수 있습니다.
- 이전/다음, 사이드바 열기와 새 회의를 상단 도구에서 사용할 수 있습니다. 알림은 사이드바 내부 상단에 있습니다.
- 축소 사이드바의 전체 목록, 폴더, 휴지통과 최근 회의에서 해당 목록을 미리 볼 수 있습니다. 최근 회의는 목록 안에서 독립적으로 스크롤합니다.
- 폴더와 최근 회의의 더보기 버튼 위치와 클릭 영역을 통일했습니다.
- Mac의 화면 이동/사이드바/새 회의 도구는 창 제목 표시줄에 통합되며 전체 화면에 맞춰 정렬됩니다.
- 휴지통 미리보기에서도 휴지통을 비울 수 있습니다. 본문의 휴지통 비우기와 같은 확인 흐름을 사용합니다.
- 참석자와 그룹, 요약 템플릿을 관리하고 Claude/ChatGPT에서 회의를 활용할 수 있습니다.
- 두 운영체제에서 여러 음성 파일 형식을 가져오고 Windows에서 Whisper를 사용할 수 있습니다.
- 새 버전을 자동으로 확인하고 다운로드하며 사이드바에서 업데이트할 수 있습니다.
- 고샘플레이트/다채널의 긴 녹음도 원본을 보존하면서 재생용 파일을 변환합니다.
- 설정에서 개인정보처리방침을 확인할 수 있으며 배포 구성 요소의 라이선스 고지를 함께 제공합니다.
- 화면 자산과 음성 처리 실행 파일의 중복 포함, 회의 상태와 폴더 집계의 반복 작업을 줄였습니다.

CLI/MCP 연결 패키지의 세대는 제품 버전과 별개인 `0.3.0-nero.36`입니다.
