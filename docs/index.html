회의 기록은 내 컴퓨터에

마이크 녹음, 음성 인식, 화자 구분과 내장 모델 요약을 로컬에서 처리합니다. 녹음, 음성 기록, 메모와 요약은 컴퓨터에 저장합니다.

macOS의 Apple Silicon과 Windows x64를 지원합니다. 지원 운영체제와 설치 안내는 다운로드 페이지에서 확인하세요.

일정에서 회의 준비

Google Calendar 연결은 선택 사항입니다. 선택한 캘린더의 일정 제목, 시간과 참가 링크를 읽어 회의를 만들고 시작 전에 알립니다. 캘린더와 일정을 추가하거나 수정하는 권한은 요청하지 않습니다.

AI 도구와 함께 사용

Claude, ChatGPT 등 연결한 도구에서 회의를 찾아 읽고 정리할 수 있습니다. 사용자가 요청하면 회의나 템플릿을 수정할 수도 있습니다. 해당 도구로 전달한 정보에는 각 도구의 데이터 처리 정책이 적용됩니다.
