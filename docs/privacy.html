개인정보처리방침

적용일: 2026년 11월 2일

이 방침은 ChoSeongmin1128이 개발 및 운영하는 Nero 데스크톱 앱의 데이터 처리에 적용됩니다. Nero는 회의 데이터를 보관하는 개발자 운영 서버나 컴퓨터 간 자동 동기화 서비스를 제공하지 않습니다.

회의 데이터

녹음, 음성 기록, 화자 표시, 메모, 요약, 참석자와 템플릿을 사용자의 컴퓨터에 저장합니다. 기본 음성 인식과 내장 모델 요약은 이 컴퓨터에서 처리하며, 이를 위해 녹음이나 회의 본문을 외부 AI 서버에 전송하지 않습니다.

데이터는 사용자가 삭제할 때까지 컴퓨터에 남습니다. 회의를 휴지통으로 옮겨도 영구 삭제 전에는 복원할 수 있습니다. 파일 내보내기, 별도 복사와 시스템 백업으로 만든 사본은 사용자가 따로 관리합니다. 앱 제거만으로 모든 회의 파일이나 운영체제 자격 증명이 지워지지는 않을 수 있습니다.

Google Calendar 연결

Google 연결은 선택 사항이며 Google 동의 화면에서 승인한 뒤 사용합니다. Nero는 캘린더 목록과 일정에 대한 읽기 권한만 요청합니다.

  • 캘린더 이름과 식별자, 연결 계정을 구분하는 정보
  • 선택한 캘린더의 일정 제목, 시작/종료 시각, 일정 식별자, 일정 상태와 유형, 반복 일정 구분과 업데이트 정보
  • 온라인 회의 참가 링크와 사용자의 일정 참석 응답 상태

이 정보는 알림을 받을 캘린더 선택, 회의 시작 전 알림, 일정에서 회의 만들기와 참가 링크 열기에 사용합니다. 일정과 캘린더를 생성, 수정하거나 삭제하지 않습니다. 알림용 일정 캐시와 캘린더 선택/알림 상태는 로컬에 저장되며 동기화 때 갱신됩니다. 날짜를 지정해 별도로 조회한 일정은 화면에서 사용하고 전체 결과를 로컬 캐시에 보관하지 않습니다. 일정에서 생성한 Nero 회의는 캘린더 연결을 해제해도 별도로 남습니다.

연결을 유지하기 위한 갱신 토큰은 macOS 키체인 또는 Windows 자격 증명 저장소에 보관합니다. 일시적인 접근 토큰은 앱 실행 중 메모리에서 사용합니다. 토큰은 Google 인증/API 요청에 사용하며 개발자 서버나 연결된 AI 도구에 제공하지 않습니다.

설정의 Google Calendar에서 연결을 해제하면 현재 연결에 사용하는 갱신 토큰을 삭제하고 캘린더 캐시를 비웁니다. Google 계정의 서드파티 연결 설정에서도 Nero 접근을 철회할 수 있습니다. 별도로 만든 회의나 내보낸 파일까지 삭제하려면 해당 항목을 따로 삭제하세요.

Nero는 Google API로 받은 사용자 데이터를 판매하거나 광고에 사용하지 않으며, 범용 AI 모델의 개발/학습에 사용하지 않습니다. Google API 데이터의 사용과 다른 앱으로의 전달은 Google API 서비스 사용자 데이터 정책과 Limited Use 요구사항을 따릅니다.

외부 AI 도구

사용자가 Claude, ChatGPT 등 로컬 도구를 연결하면 해당 도구가 요청한 회의와 템플릿 정보를 읽을 수 있습니다. 사용자의 요청과 해당 도구의 승인 정책에 따라 수정, 휴지통 이동과 작업 취소도 가능합니다. Google 일정에서 복사한 회의 제목과 날짜도 요청한 회의 조회에 포함될 수 있습니다. 외부 도구가 읽은 내용은 해당 도구의 모델 서비스로 전송될 수 있으며 이후 처리는 그 서비스의 정책과 설정을 따릅니다.

모델, 업데이트와 웹사이트

모델 준비와 앱 업데이트 확인/다운로드에는 Hugging Face와 GitHub 등의 제공 서버에 접속합니다. 이때 제공 서버는 네트워크 주소와 요청 정보를 처리할 수 있습니다. 이 다운로드 요청에 녹음, 음성 기록이나 요약 본문은 포함하지 않습니다.

이 안내 웹사이트는 GitHub Pages에서 제공합니다. 별도의 광고, 분석 스크립트나 추적용 쿠키를 추가하지 않습니다. 웹사이트 제공에 필요한 접속 정보는 GitHub의 정책에 따라 처리됩니다.
