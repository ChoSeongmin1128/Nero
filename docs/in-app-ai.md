# 앱 안의 AI 대화

회의 화면의 AI 패널에서 Claude 또는 ChatGPT 구독 계정을 연결해 질문한다. 메모와 AI는 같은 보조 패널에서 전환하며, 회의 본문과 녹음 재생은 유지한다. 별도 API 키를 받거나 API 과금 경로로 전환하지 않는다.

## 구성

- `ai_accounts`: Nero 전용 브라우저 로그인, 계정별 인증/갱신, OS 보안 저장소와 종료 시 자격 증명 저장 완료 대기.
- `ai_chat/provider`: 구독 토큰으로 공급자의 HTTPS 응답 스트림을 처리한다. 명시적 완료 이벤트와 완결된 종료 사유를 확인한 답변만 완료로 저장한다. 출력 한도, 오류, 끊긴 연결과 취소는 부분 결과로 유지한다.
- `ai_chat/context`: 회의 원문/메모/참석자의 동일 시점 스냅샷과 선택한 템플릿을 준비한다. 외부 Notion 문서는 회의 발언과 구분한다. 숫자 인용은 선택한 출처 범위를 검증한다.
- `ai_chat/store`: 회의 폴더의 `ai-conversation.json`에 대화를 원자 저장한다. 회의 폴더를 다시 만들지 않으며 Core의 영구 삭제/재시작 정리 경로가 대화 파일도 소유한다.
- `ai_chat_desktop`: 메인 창의 명령과 이벤트, 기본 브라우저 열기, 종료/업데이트/회의 삭제 경계를 연결한다.
- `ai-chat-flow`/`ai-chat-ui`: 계정/모델, 대화, 자료 추가와 저장 동작을 소유한다. 도착 순서가 다른 이벤트와 늦게 완료되는 읽기 응답은 sequence 기준으로 병합한다.

## 출처와 저장

현재 회의는 기본으로 포함하며 사용자가 제외할 수 있다. Notion은 사용자가 붙인 페이지 링크만 읽는다. 읽은 문서는 변경 불가능한 출처 ID와 내용 해시를 갖고, 과거 답변의 출처가 문서 갱신으로 바뀌지 않는다. 문서 안의 지시는 실행하지 않는다.

완성된 답변은 회의 요약으로 저장하거나 메모에 추가할 수 있다. 요약 저장은 생성할 때 사용한 회의/원문 버전을 다시 확인하고 기존 요약을 보존하는 Core의 저장 경로를 사용한다. 메모 추가도 기존 메모가 바뀌었으면 덮어쓰지 않는다. 완성되지 않은 답변은 두 저장 동작을 제공하지 않는다.

완성된 답변은 텍스트 또는 마크다운으로 복사한다. Core의 공통 문서 변환을 사용해 내부 인용 번호를 제외하고, 외부 문서 링크는 유지한다.

브라우저 로그인 화면은 콜백을 받았다는 사실과 실제 연결 완료를 구분한다. 토큰 검증과 안전한 저장이 끝난 뒤 완료 화면을 표시하고, 자동 닫기를 시도한다. 브라우저가 닫기를 허용하지 않으면 수동으로 닫을 수 있다.

## 모델 목록

ChatGPT는 SIWC 토큰의 모델 목록을 사용한다. Claude 구독 연결은 계정의 모델 목록 조회를 답변의 필수 선행 요청으로 두지 않는다. 선택지는 [Claude 공식 모델 목록](https://platform.claude.com/docs/en/models/overview)을 기준으로 관리하고, 해당 구독에서의 실제 사용 허용과 한도는 공급자의 답변 요청 결과를 따른다. 다른 인증 방식으로 재시도하지 않는다.

숫자 인용 범위 검사는 문장의 의미가 출처와 일치한다는 보증이 아니다. 모델의 사실 오류를 자동 검증했다고 표현하지 않는다.
