# 앱 안의 AI 대화

이 문서는 현재 소스의 동작을 설명한다. 배포된 버전의 기능은 릴리스 안내를 확인한다.

앱 우측의 AI 사이드바에서 Claude 또는 ChatGPT 구독 계정에 로그인해 질문한다. 대화는 회의와 독립적으로 유지한다. 화면을 이동해도 같은 대화를 계속 사용하며, 회의 메모와 AI를 동시에 열 수 있다. 별도 API 키를 받거나 API 과금 경로로 전환하지 않는다.

## 대화와 첨부

새 대화, 대화 목록과 삭제를 제공한다. AI 창은 화면의 회의를 따라간다. 회의를 열면 그 회의를 첨부해 질문한 가장 최근 대화를 보여 주고, 없으면 그 회의를 첨부한 새 대화를 띄운다. 새 회의는 항상 새 대화로 시작한다. 보내지 않은 초안은 그 회의로 돌아오면 다시 나타난다. 회의 목록 같은 회의가 없는 화면은 현재 대화를 바꾸지 않는다. 하나의 대화에서 여러 회의를 사용했다면 각 회의에서 그 대화가 열린다. 회의 화면의 대화 목록은 기본적으로 해당 회의의 대화를 보여주며 전체 대화로 전환할 수 있다. 사용자가 첨부를 제거하거나 다른 회의를 추가할 수 있고, 기존 대화를 열 때 현재 회의를 자동으로 추가하지 않는다. Notion은 사용자가 지정한 페이지만 읽는다. 회의를 첨부하면 그 회의에 저장된 Notion 자료도 대화의 제거 가능한 자료로 표시한다. 같은 페이지가 여러 회의에 있으면 첨부 순서상 첫 회의의 저장된 버전을 선택하며, 직접 추가한 버전이 있으면 이를 우선한다. 회의를 대화에서 제거하면 남은 회의의 버전으로 선택이 바뀔 수 있다. 질문을 보낼 때 선택 출처를 함께 저장해 대화를 다시 열어도 유지한다. 이전 기록에 선택 출처가 없으면 당시 선택한 자료를 그대로 유지한다. 회의 자료의 갱신이나 제거는 이미 대화에 선택된 자료를 자동으로 바꾸지 않는다.

질문을 보낼 때 회의 원문/메모/참석자와 선택한 Notion 문서를 변경 불가능한 입력 스냅샷으로 묶는다. 여러 회의의 발언과 외부 문서를 구분하고 인용 번호는 해당 요청 안에서 고유하게 부여한다. 문서 안의 지시는 실행하지 않는다. 과거 메시지의 첨부와 출처는 이후 화면 이동이나 원문 수정으로 바뀌지 않는다.

회의를 휴지통으로 옮기거나 삭제해도 대화와 진행 중인 답변은 유지한다. 삭제된 회의를 새 질문에 첨부하면 요청을 거절하며, 과거 스냅샷을 자동으로 다시 전송하지 않는다. 대화를 삭제하면 해당 대화의 답변만 중지하고 대화는 AI 대화 휴지통으로 옮긴다. 휴지통의 대화는 복원하거나 완전히 삭제할 수 있고, 이어서 질문하려면 먼저 복원한다. 기간이 지나도 자동으로 지우지 않는다.

사이드바의 AI 대화는 가운데에 대화 목록을, 오른쪽에 AI 창을 연다. 목록은 대화마다 질문에 첨부한 회의를 보여 주며 대화를 눌러도 회의 화면으로 이동하지 않는다. 여러 대화를 골라 휴지통으로 옮기거나, 마지막 대화가 10일, 30일, 90일보다 오래된 대화를 한 번에 옮기거나, 전체를 옮길 수 있다. 답변 중인 대화는 한꺼번에 정리할 때 제외한다.

보낸 질문은 수정해 다시 물을 수 있다. 수정한 질문은 원래 질문과 같은 자리에서 새 버전이 되고, 그 아래 이어진 대화는 이전 버전에 남는다. 새 답변은 수정한 지점 이전의 대화만 맥락으로 받는다. 버전은 질문 옆에서 바꿔 볼 수 있고 마지막으로 고른 버전을 기억한다. 입력창이 비어 있을 때 위 화살표를 누르면 현재 대화에서 보낸 질문을 최근 것부터 불러오고, 아래 화살표로 되돌아가면 쓰던 초안이 돌아온다.

## 회의 요약과 템플릿

`/회의요약`은 회의 하나와 사용자가 명시적으로 선택한 템플릿이 필요하다. 입력 영역의 템플릿 칩에서 템플릿을 바꾸거나 선택을 해제할 수 있다. 전송 시 선택 ID로 저장된 최신 템플릿을 읽어 이름, revision과 프롬프트를 요청 스냅샷에 보존한다. 이후 템플릿을 수정하거나 삭제해도 이미 보낸 요청은 바뀌지 않는다. 재시도는 선택한 템플릿 ID를 유지하고 전송 시점의 저장된 내용을 다시 읽는다.

완료된 `/회의요약` 답변은 지정한 회의의 요약으로 저장을 시도한다. 저장은 기존 회의 맥락과 버전을 검사하며, 저장 성공 응답을 확인해야 완료로 표시한다. 실패한 경우 오류를 표시하고 기존 내용을 보존한다.

## 답변 표시

답변과 요약은 CommonMark와 GFM(표, 체크 목록, 취소선, 인용, 링크)으로 해석해 허용한 태그로만 그린다. 모델이 쓴 HTML은 실행하지 않고 글자로 보여 준다. 링크는 계정 정보가 없는 https 주소만 외부 브라우저로 열며 앱 창 안에서는 이동하지 않는다. 생성 중인 답변은 덜 끝난 서식을 닫아 표시하고, 끝에 걸린 미완성 인용 번호는 완성될 때까지 표시하지 않는다.

## 저장과 복사

완성된 답변은 첨부된 회의 중 사용자가 선택한 회의의 요약으로 저장하거나 메모에 추가할 수 있다. 생성할 때 캡처한 대상 회의의 버전과 원문 맥락을 다시 확인하며, 편집된 내용을 덮어쓰지 않는다. 같은 답변을 같은 대상에 중복 저장하지 않는다. 완성되지 않은 답변에는 저장 동작을 제공하지 않는다.

여러 회의를 다룬 답변을 한 회의에 저장할 때 그 회의의 인용 번호만 원문 번호로 대응한다. 다른 회의의 발언은 회의명과 시각으로 구분하고 Notion 인용은 외부 링크로 유지한다. 숫자 인용 범위 검사는 문장의 의미가 출처와 일치한다는 보증이 아니다.

완성된 답변은 텍스트 또는 마크다운으로 복사한다. Core의 공통 문서 변환을 사용해 내부 인용 번호를 제외하고 외부 문서 링크를 유지한다. 복사는 특정 회의의 존재나 선택을 요구하지 않는다. 회의 기록과 AI 답변의 복사는 본창 전용 네이티브 클립보드 쓰기를 공유하며 브라우저의 일시적인 클립보드 권한에 의존하지 않는다. 복사할 내용은 16 MiB로 제한하고 쓰기 실패는 사용자에게 알린다.

## 저장 구조와 연결

- `ai_chat/store`: 앱 데이터의 `ai-conversations/<UUID>.json`에 대화를 원자 저장한다. 회의 폴더를 만들거나 다시 생성하지 않는다. 이전 회의별 대화는 네이티브 작성자의 첫 전역 대화 사용에서 멱등 수입하며 원본을 보존한다. 수입 기록은 삭제한 대화가 다시 나타나지 않도록 한다. 메시지는 앞 메시지(`parentId`)를 기억하고, 대화는 갈라진 지점마다 보여 줄 질문 버전(`versions`)과 휴지통으로 옮긴 시각(`deletedAt`)을 함께 저장한다. 이 정보가 없는 이전 파일은 순서대로 이어진 하나의 대화로 읽는다. 일반 CLI/MCP 조회는 수입이나 마이그레이션을 실행하지 않는다.
- `ai_chat/context`: 첨부된 회의별 버전/요약 맥락과 고유한 인용 번호, Notion 출처 ID/내용 해시, 입력 스냅샷을 묶는다.
- `ai_chat/provider`: ChatGPT의 HTTPS 응답 스트림을 처리한다. `claude_runner`: 서명을 확인한 공식 Claude Code 실행기의 구조화 스트림을 처리한다. 완료 여부를 확인하고 오류와 취소 시 부분 결과를 보존한다.
- `ai_accounts`/`notion_context`: ChatGPT와 Notion의 Nero 전용 로그인, 자격 증명 저장과 갱신을 담당한다. Claude 인증은 Claude Code가 소유하며 Nero는 기존 Claude 자격 증명을 읽거나 복사하지 않는다.
- `meeting_context`: 회의별 Notion 자료의 불변 출처 ID를 저장한다. 문서 본문은 공통 Notion 캐시에만 저장한다.
- `ai_chat_desktop`: 메인 창의 명령과 이벤트, 브라우저 열기, 종료/업데이트 경계를 연결한다.

ChatGPT와 Notion의 브라우저 로그인 화면은 콜백 수신과 실제 연결 완료를 구분한다. 토큰 검증과 안전한 저장이 끝난 뒤 완료 화면을 표시하고 자동 닫기를 시도한다. 브라우저가 닫기를 허용하지 않으면 사용자가 닫을 수 있다.

설정의 `AI 계정`은 Nero 내부 대화에 사용할 로그인이다. `MCP 연결`은 다른 AI 앱에 Nero 도구를 등록하는 연결이며, `Notion 연결`과 `Google Calendar`는 별도로 관리한다. Notion의 내부 통신이 MCP여도 외부 AI 앱의 Nero 도구 등록과 구분한다.

계정 상태 화면은 공개 메타데이터만 읽고 자격 증명이나 인증 확인 실행기를 자동 호출하지 않는다. 앱 재시작 후 확인되지 않은 계정을 로그아웃으로 단정하지 않는다. 모델 선택은 서비스별로 묶인 하나의 목록을 사용한다. 모델 메뉴를 열면 캐시된 목록과 선택을 즉시 표시하고, 앱 실행 중 계정마다 한 번 최신 목록을 받는다. 앱 시작, 설정 화면과 대화창 열기는 목록을 받지 않는다. 목록을 받지 못하면 기존 캐시와 선택을 보존하고 다시 시도를 제공한다.

ChatGPT는 Sign in with ChatGPT로 연결하고 계정의 모델 목록을 사용한다. macOS는 계정 자격 증명을 제한된 단일 키체인 항목에 저장하며 Windows 항목 크기 제한용 청크 저장과 구분한다. 기존 macOS 항목은 앱 프로세스의 비대화형 접근 범위 안에서 읽고 원래 UI 허용 상태를 복원한다. 복원에 실패하면 이후 저장소 접근을 중단한다. 기존 항목을 읽지 못하면 여러 항목의 암호를 연속 요청하지 않는다. 명시적으로 새 로그인을 완료해 검증/저장하기 전까지 기존 항목과 계정 목록을 보존한다. Claude는 사용자가 공식 Claude Code에 직접 로그인하며 실제 사용 결과와 명시적 로그인에서 상태를 확인한다. 앱은 수정하지 않은 공식 실행 파일의 서명을 확인하고, 필요 시 앱 전용 실행기를 준비한다. 기존 Claude Code 로그인 상태는 Nero에서도 사용할 수 있으며 Nero에서 연결을 해제하려고 외부 Claude Code를 로그아웃하지 않는다. Claude 모델 목록은 공식 실행기의 `supportedModels()`가 제공하는 이름과 ID를 사용하며 별칭에서 버전을 추측하지 않는다. 모델 목록은 로그인 완료 시 준비하고 저장된 목록을 다시 보여 준다. 모델별로 확인된 추론 수준은 모델 옆에서 선택할 수 있으며, 기본값은 공급자에 맡긴다. 지원 정보가 없으면 확인 불가로 표시한다. ChatGPT 목록에 지원 정보가 없을 때는 OpenAI 모델 문서에서 확인한 정확한 모델 ID의 설정만 제공한다. 요청한 모델 ID와 실제 응답에서 제공된 `actualModelId`는 별도로 기록한다. 실제 계정의 사용 가능 여부는 실행 결과를 따른다.

Claude 요청은 별도 임시 작업 위치에서 도구와 MCP를 제한하고 세션을 저장하지 않는다. 사용자에게 터미널을 표시하지 않는다. 조직이 관리하는 정책은 계속 적용될 수 있다. 선택한 회의와 자료의 내용은 답변을 위해 해당 서비스에 전달된다.
